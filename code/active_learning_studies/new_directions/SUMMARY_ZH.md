# 一页中文摘要(隔夜探索,分支 `claude/new-directions-overnight`)

完整结果、表格和注意事项在 `NEW_DIRECTIONS_RESULTS.md`;逐步日志在 `OVERNIGHT_LOG.md`。以下全部基于**同一批 168 个标注配对组**(用新随机种子重新划分,不是新数据)、冻结 SimCLR 特征的头部模型,在 CPU 上完成。

## 最重要的发现(已预注册并在新种子上确认)
**把"参考图(理想图)排序损失"的权重从 0.25 提高到 8**,留出配对的偏好预测明显变好(35 个新种子、两种划分、12 个预注册检验全部显著,Holm ≤ 0.003):
- AUC +0.012(A 划分)/ +0.019(B),准确率 +0.019 / +0.023,log-loss +0.052 / +0.065。
- 把全部 144 张理想图都当锚点(`aw8_all`)再好一点:AUC +0.020 / +0.024。
- 冷启动(只有 10 条随机初始判断)时增益更大:AUC +0.022 / +0.028(预注册 3,新种子 4000–4034)。
- 论文自己的终点——28 张外部测试理想图的类型准确率——也提高 +0.043(预注册 2,Holm < 0.0001),但水平仍是 0.83–0.85,没有超过最简单的对照(最近邻 0.871)。

## 它改变了什么结论
- 之前报告的"`vopt_u` 优于随机"在默认学习器上**仍然成立**(新种子重复:AUC +0.010 / +0.013,准确率 +0.016 / +0.022)。
- 但换成锚点权重 8 的学习器后,**`vopt_u` 相对随机的优势不再成立**(AUC +0.002 / +0.005,准确率 +0.000 / +0.002,Holm 0.75 / 0.20 / 1.0)。冷启动下 A 划分边缘(Holm 0.07 / 0.05),B 划分没有。
- 也就是说:一个很便宜的学习器改动,收益 ≥ 选择规则的收益,并且吞掉了它。之前对选择策略的比较,是在锚点权重没调过的学习器上做的。
- 开发种子上,旧的 30 个选择策略在调好的学习器下,**没有一个**在多重校正后显著优于随机。

## 一个重要的坏消息
**对 HTR(实验室最关心的类型)没有确认的增益**(预注册 4,新种子 5000–5034):HTR 准确率 +0.015(A)/ +0.032(B)(全部理想图当锚点),Holm 0.95 / 0.68;只用参考图时,HTR 的 log-loss 在 A 划分显著变差(−0.073,Holm 0.017)。整体增益来自 (1x1)、√13 和 c(6x2)。之前"HTR 只有在用全部理想图时才受益"的探索性观察没有重复出来。
