# Literature support per direction (what is verified and what is not)

How the citations were checked: three-plus search sessions through a web-search tool. The pages themselves could not be opened (DNS / proxy failures for arxiv.org, aclanthology.org, mlr.press), so every entry was
confirmed only from search-result titles, authors, venues and URLs, usually in two or more independent results. Statements about what a paper "says" come from search summaries and abstracts, not from reading
the full text. Entries marked UNVERIFIED / PARTIAL in the files `lit_*.md` are not used below unless stated. The three files remain the source of the URLs.
