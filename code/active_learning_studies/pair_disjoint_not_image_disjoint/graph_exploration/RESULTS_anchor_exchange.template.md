## 2. Setting
Learner everywhere: `lap3_k10_st4` (Bradley-Terry head on frozen SimCLR features; anchor ranking loss with weight 8; Laplacian regulariser λ = 3 on the cosine kNN graph, k = 10, over the unlabelled images; head trained 4× longer), the best learner of the earlier confirmed studies. One change: the anchor term uses only a chosen subset of the ideal images. Main endpoint: held-out pair-group preference prediction (AUC, accuracy, log-loss; overall and per type), splits A and B, pairwise budgets 10/20/40/60 judgments on top of the 10 initial groups (+ budget 0 = initial groups only for the dose-response). Extra endpoint: type accuracy of the 28 outer-test ideal images (the paper's endpoint, win-rate rule with the selected anchors as the reference set; classes without any anchor cannot be predicted).

Protocol facts and extensions (pre-registered):
- Only about 154 ideal images carry type labels; trajectory images have none (the absolute-label file has 18 'Bad' images only). So the value of typed labels of **new trajectory frames cannot be evaluated on existing data**; the exchange rate below is for ideal-image anchors, and transfers to trajectory frames only as a hypothesis (prospective experiment in `GPU_TASKS_anchor_exchange.md`).
- Anchor universe = the 116 non-test ideal images (88 references + 28 utility-validation). The 28 outer-test ideal images are never anchors and never graph nodes. The original `aw8_all` also used them as anchors (144 anchors); that arm is kept as a reference (see the 144-vs-116 comparison below).
- The graph's node set does not change with the anchor subset (all non-test ideal images stay as unlabelled nodes; only chosen ones carry labels). With every anchor of the 144 universe selected the learner reproduces `lap3_k10_st4` exactly (unit test, max difference 0.0).
- Active anchor rules choose the subset without the labels of unselected images; the sequential rules (`htrq`, `amb`, `kcf_bal`) use only the labels of anchors already chosen. Random anchors are drawn without class stratification (the class is unknown before labelling).
- Exchange rate: extra pairwise judgments equivalent to extra anchors, from a log-axis model of the budget curve fitted per anchor level (30 + budget = total judgments), with a seed bootstrap (1000 resamples, 95% percentile interval); 'beyond range' = the equivalent exceeds the 60 extra judgments measured; an interval upper end of `inf` means the bootstrap could not bound it. No significance claim.

Candidates frozen before confirmation: `htrq` (+ shuffled-graph control), `kcf`, `kcg` (+ control), `typi`; success rule: all four gains positive (A/B × AUC/accuracy), ≥ 3 of 4 Holm < 0.05 (family 16), and, for the graph rules, beating the shuffled-graph control.

## 6. Limitations
Same 168 pair groups and 150 ideal images in every seed → optimistic p-values and intervals. The anchor universe is only 116 images, and the 36-anchor budget is one point of the curve; 'random' anchors are unstratified, so at small counts some classes are absent (this is part of what the dose-response measures). The exchange rate depends on the learner (frozen features, one learner), on the budget region (it is large at low pairwise budgets and shrinks as judgments accumulate) and on the endpoint; the per-type numbers rest on 12–16 test judgments per seed (HTR) and are noisy. The bootstrap treats seeds as independent although every seed re-splits the same pair groups. Literature notes rest on search-result summaries (no paper text opened). No cost data exist: the exchange rate is in labels, not minutes.
