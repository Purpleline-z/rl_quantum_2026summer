# 开发方案 GM0(写于任何开发结果之前;分支 claude/graph-mechanism-20261013)

**问题**:在调好的基线上加"无标注图像 kNN 图的拉普拉斯正则"的增益(上一轮 `lap{1,3,10}_k10`),来自**图的质量**还是**任何一种平滑**?如果来自图质量,换更好的图应当更好。

**基线**:`aw8_all`(原基线)和 `lap3_k10`(新基线,每个开发变体都与这两者在相同随机标注集上配对)。开发种子 8000–8019(20 个,划分 A、B,3 次抽样,预算 10/20/40/60);协议不变(judgment-unit,留出配对组的偏好终点:AUC、准确率为主,log-loss、HTR 为次)。代码:`new_directions/nd_graph_mechanism.py`(与 `lap3_k10`/`lap3_k10_n3` 逐数值一致,有测试)。

**开发轮次(每轮 ≤12 个变体,共 4 轮;全部列在 RESULTS 里,含失败的)**
1. 剂量-响应:噪声 σ∈{0.5,1,2,3} × λ∈{3,10},λ=10 的 σ=0 参考,λ=3 的 σ=0 记录(= lap3_k10)。图质量 = 理想图-理想图边中同类占比(`graph_quality`),每个种子、划分、图单独记录。
2. 其他图构造(λ=3):互 kNN(k=15)、ε 图(平均度 10)、共享近邻、高斯核边权、局部尺度核、b-matching(b=10)、PCA 白化(32 维)、SimCLR 第 2/3 层与 3+4 层特征、归一化拉普拉斯。
3. 作用位置与非图正则:只对无标注-无标注边 / 只对理想图-轨迹边、HTR 加权;非图对照(高斯输入噪声,尺度=kNN 邻居距离;mixup 一致性;weight decay 1e-3/1e-2)、λ 退火(衰减/上升)。(manifold-mixup 一致性被去掉:最后一层是线性的,隐层插值的一致性恒成立,没有信息。)
4. 第 1–3 轮后的组合/细化(≤12 个),只在 σ、构造、位置里已经显示出方向的变体上做。

**纪律**:开发只用来设计和筛选;至多冻结 4 个候选,连同各自的打乱图、噪声图(σ=3)、最强非图对照一起写入 `PREREGISTRATION_GM1.md` 并提交,**之后**才跑确认(8100–8134,可能 8150–8184)。开发数字有赢家诅咒,不当证据。
