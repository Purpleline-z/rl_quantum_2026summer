# PREREGISTRATION_E0 — development plan (anchor-exchange study; written 2026-10-13 before any development result)
Branch `claude/anchor-exchange-1013` (from `claude/selection-htr-20261013`). Learner for everything: `lap3_k10_st4` (aw8_all loss, anchor weight 8, Laplacian lambda 3 on the cosine kNN graph k = 10, head trained 4x longer) — the best learner of the earlier confirmed studies. Endpoint: held-out pair-group preference prediction (AUC, accuracy, log-loss; overall and per type), splits A and B, pairwise budgets 10/20/40/60 on top of the 10 initial groups (+ budget 0 = initial groups only for the dose-response). Seeds: development 8700–8719 (only the first 10–14 are used per screen), confirmation 1 = 8750–8784; own block registered in `nd_core.py` (the blocks 8000–8199, 8400–8599 and the rest of 8600–8999 belong to parallel studies).

## Facts and protocol extensions (all marked)
F1 Only about 154 ideal images carry type labels; trajectory images have none (the absolute-label file has 18 'Bad' images only). So the value of labelling NEW trajectory frames cannot be evaluated on existing data. The study measures the value of typed labels of IDEAL images (anchors) relative to pairwise judgments; a prospective experiment with new trajectory frames is a GPU/lab task.
E1 Anchor universe: the 116 non-test ideal images of a seed (88 references + 28 utility-validation; classes known to the lab once labelled). The 28 outer-test ideal images never enter the graph or the anchors and form the external endpoint. (The original `aw8_all` also used the 28 outer-test images as anchors: that is the 144-anchor universe, kept as one reference arm and for the exact-reproduction test; "100% anchors" of this study = 116.)
E2 When the anchor subset changes, the graph node set does not change (every non-test ideal image stays an unlabelled node; only chosen ones carry labels). With every anchor of the 144 universe selected the learner reproduces `lap3_k10_st4` exactly (unit test; measured max difference 0.0).
E3 External endpoint (extra): type accuracy of the 28 outer-test ideal images by the paper's win-rate rule, using the SELECTED anchors as the reference set; classes without anchors cannot be predicted.
E4 Active anchor rules choose the subset in one batch (or in 3 rounds of 12 for the sequential rules) WITHOUT the labels of unselected images; sequential rules see only the labels of anchors already chosen. Random anchors are drawn without class stratification (the class is unknown before labelling).

## Development variants (<= 10 selection variants, development seeds)
Dose-response: anchors n in {0, 12, 29, 58, 116} (0%, 10%, 25%, 50%, 100% of 116; 3 random subsets for the partial levels) x pairwise budgets {0, 10, 20, 40, 60}; plus the 144-anchor reference arm. Exchange rate: for each reference cell, the number of extra pairwise judgments b* that matches the gain of a given number of extra anchors (interpolated in log(n_pairs) on the budget axis), reported per type and overall with seed-bootstrap intervals; only within the measured range, otherwise marked "beyond range".
Active anchor rules at 36 anchors (about 31% of 116): `rand` (3 subsets), `kcg` graph k-center (hop distance on the kNN graph) + `kcg_shuf`, `kcf` feature k-center, `typi` TypiClust, `amb` label-spreading ambiguity (sequential) + `amb_shuf`, `htrq` HTR quota (half of every round the most HTR-like, half the most ambiguous) + `htrq_shuf`. Interaction with lambda: lambda in {0, 3, 10} x anchors {0, 29, 116} x budgets {20, 60}.
Freeze rule: <= 4 candidate rules (+ controls) and their family in `PREREGISTRATION_E1.md`, committed before any seed >= 8750 runs. Success rules (as in the task): (a) an active anchor rule beats random anchors of the same count with positive AUC and accuracy in A and B, at least 3 of 4 Holm p < 0.05 (candidates x 2 splits x 2 metrics), and beats its shuffled-graph control; (b) the exchange rate is reported as an estimate with an interval, no significance claim. Otherwise "not confirmed".
