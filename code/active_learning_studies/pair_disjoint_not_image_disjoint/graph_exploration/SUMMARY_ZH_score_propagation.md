# 一页中文摘要:不带参数头的"分数传播"模型,以及它和拉普拉斯头 `lap3_k10_st4` 的混合(分支 `claude/score-propagation-20261014`,2026-10-14)

完整结果和所有表格(脚本生成)在 `RESULTS_score_propagation.md`。仍然是**同一批 168 个标注配对组和 3 条生长轨迹**(换种子重新划分,不是新数据),冻结 SimCLR 特征,CPU 完成。开发种子 11200–11219;预注册确认 1 = 11230–11264(35 个,只跑一次),确认 2 = 11265–11299(只重复主方案)。

## 问的问题
`lap3_k10_st4` 的增益里,有多少只是"插值"——一个完全不带参数头的非参数方法本来就能给出的?非参数/混合模型能不能超过它?

## 预先登记并确认的结果(35 个种子,Holm 校正)
- **纯非参数模型明显更差。** 给每张图每个类型一个自由分数(配对似然 + 锚点排序 + 全图拉普拉斯,无任何头)比头低 AUC −0.025/−0.026、准确率 −0.043/−0.049(划分 A/B,4/4 显著)。差距集中在**远离锚点**的判断(AUC 约 −0.10 到 −0.13);靠近锚点的判断只差 −0.019/−0.014。在靠近锚点的层里,自由分数拿到了**头相对"不用图的头"的增益的大约一半**(48% [20%, 69%] / 55% [8%, 94%]);远离锚点则一点也没有。只用锚点做标签传播(−0.065)、最近邻(−0.052)更差;打乱图(−0.39)和去掉图惩罚(−0.23)直接崩溃,说明插值确实靠图。
- **"头 + 自由分数残差"和"用自由分数蒸馏头"没有帮助**:残差混合 AUC −0.003、准确率 −0.009(更差);蒸馏在 0.003 AUC / 0.01 准确率的边界内**不劣于**但没有增益。
- **主结论:只把 HTR 的判断改用自由分数(其余三个类型仍用头)比 `lap3_k10_st4` 更好**:AUC **+0.0079/+0.0049**,准确率 **+0.0048/+0.0034**(A/B);4 个主检验里 3 个 Holm 显著(划分 B 的准确率未校正 p=0.017,Holm 后 0.10)。HTR 准确率 +0.032/+0.026。增益依赖图(打乱图 −0.04,去掉惩罚 −0.02),而且在**远离锚点**的判断上也为正(AUC +0.018/+0.004,准确率 +0.011/+0.009;4 个都为正,2 个 Holm 显著)——这是本项目第一个确认的"远离锚点"增益。
- **独立重复(确认 2,另外 35 个种子)**:AUC +0.0088/+0.0057,准确率 +0.0056/+0.0034,4 个检验全部 Holm 显著。次要评估(确认 1 种子):冷启动 AUC +0.0082/+0.0057;按时间分块划分 AUC +0.0055、准确率 +0.0043。
- 必须如实说:增益**很小**,而且**全部来自 HTR 判断**(约占测试判断的 15%,头在 HTR 上本来就有 93–98% 的准确率);其余类型按构造不变。要路由哪个类型、缩放系数 c=2,都是在开发种子上看过分类型表之后定的(事后选择;确认种子是新的,两套新种子结果一致)。汇总 AUC 的增益有一部分来自缩放(跨类型校准),HTR 类型内的准确率增益(+0.03)不依赖缩放。机制:HTR 的锚点最少(144 个里只有 26 个),头在 HTR 上较弱,传播已标注的 HTR 判断和锚点补上了这个缺口;增益在"离已标注帧最远"的 HTR 测试图上最大(+0.058 vs 最近三分之一的 +0.007),所以不是对近似重复帧的记忆。

## 只是开发观察(开发种子,不算证据)
- 自由分数的 λ、ρ、锚点权重、核宽度对结果影响很小(≤0.01 AUC),ρ 小对 HTR 和远离锚点更好;其他类型改用自由分数都是负的。按时间分块,开发种子上 HTR 路由几乎为 0(+0.0004),确认种子上为 +0.0055,所以分块证据并不一致。
- 交叉验证堆叠(只在开发里跑了 8 个种子,每格约 30 秒)权重随机漂移,比头差 0.009–0.011 AUC。
