## 跨对话的共同结论(整合者的归纳,不是任何单个会话的预注册结论)
1. 没有任何一个 D–K 方向在预注册下给出"离锚点远(far)的 AUC 增益":F、E、H、I(C1)、K 的 far 层都没有 Holm 显著增益;唯一例外是 I 的 C2(两头平均)的预注册 far 家族两次确认,代价是近锚点准确率 −0.004~−0.005,以及 J 的 HTR 路由(far AUC +0.018/+0.004,2 个 Holm 显著,但整体增益很小)。
2. 打乱图对照在所有研究里都"灾难性变差"(AUC −0.07~−0.15),所以"赢打乱图"是弱声明;需要靶向对照或无图对照(E 的只用图先验、H 的无图核 β=0、D 的随机投影图、我的 `C:` 与 `:tshuf`)。多个研究发现无图/弱化版本几乎一样好(E:只用图先验≈潜在类型;H:无图核仅低 0.003–0.005 AUC)。
3. 数据质量发现(D、I 独立得到):154 张理想图里 18 张(10 HTR、8 RT13)是 16 位 PNG,被 `convert("L")` 截断成饱和白盘(特征两两余弦 0.9999);(1x1)/c(6x2) 理想图是未裁剪的整幅图(含直接束斑)。需要和实验室确认预期预处理。修正解码本身不改善结果(D),但"遮束斑+修正"的锚点在 far 层 AUC +0.03(I)。
4. 组级(而非 seed 级)推断普遍更宽:K 的组 bootstrap 区间比 seed 级宽 1.3–2.0 倍,F 的聚类 SE 是 2–3 倍,我的前向开发中组 bootstrap 区间宽 3–5 倍;分块/前向结果也是同一 168 组的重分,不算新批次。
5. 共同缺口依旧:新生长 run 的前瞻测试(各 GPU_TASKS 的第一项);远离锚点的泛化;HTR 需要更多理想图/判断。
