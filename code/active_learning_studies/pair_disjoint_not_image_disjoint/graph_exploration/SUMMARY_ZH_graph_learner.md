# 一页中文摘要:图增强学习器(分支 `claude/graph-learner-20261012`)

完整表格(全部由脚本生成)在 `RESULTS_graph_learner.md`;预注册在 `PREREGISTRATION_G0/G1`;下面所有数字都是同一批 168 个标注配对组、冻结 SimCLR 特征的头部模型的结果(换随机种子重新划分,不是新数据,所以 p 值偏乐观)。

## 结论(按"预先登记的确认"和"开发观察"分开写)
**预先登记并在新种子上确认的:**
- 在调好的基线 `aw8_all` 上,加一项"无标注图像的流形(拉普拉斯)正则"——对图像相似度 kNN 图(k=10)上相邻图像,要求它们的类型得分接近——留出配对组的偏好预测变好。三个候选(λ=1、3、10)按冻结规则(AUC 和准确率在 A/B 两个划分里差值都为正,4 个检验里至少 3 个 Holm<0.05,并优于自己的打乱图对照)在**确认 1(种子 7100–7134)**全部通过,在**独立重复(确认 2,7200–7234)**和**冷启动确认(7300–7334)**也通过。
- 效应大小:AUC 约 +0.01 到 +0.02,准确率约 +0.01 到 +0.02;和之前"参考图损失权重 0.25→8"的收益差不多大。确认 2 的效应比确认 1 小,真实效应大概比确认 1 的点估计小。
- 第 4 个候选(拉普拉斯 + 类型后验排序项)在确认 1 和冷启动通过,但**确认 2 没通过**(4 个检验 0 个 Holm 显著),所以不算稳健确认。

**开发种子上的观察(只是观察,不是证据):**
- 两层 GCN、SGC 编码器、单独的类型后验先验、一致性/岭这类"不用图的正则",都没有增益,GCN/SGC 在 k=10 时还更差。
- 打乱图对照比基线差很多——所以"优于打乱图"是很低的门槛。更有信息量的是我额外加的"噪声图"对照(图越差,结果越差):λ=10 时真图明显优于噪声图;λ=3 时多数行优于;λ=1 时和噪声图统计上分不开。所以证据倾向于"在足够准的图像相似度图上做平滑有帮助",但**不能证明这个 kNN 构造本身是关键**,也没试别的相似度图。
- log-loss:λ=10 变差,λ=1–3 持平或略好。
- HTR(实验室最关心的类型):次要(探索性)家族里 HTR 准确率在三次确认里都有几个百分点的增益,但 HTR 留出对很少,指标很粗,而且不在成功标准里;之前 `aw8_all` 没有 HTR 确认增益。只当作值得前瞻性验证的线索。

## 没做/限制
- 只试了一种图(冻结 SimCLR 的余弦 kNN);没做端到端微调、别的编码器(见 `GPU_TASKS_graph_learner.md`)。
- λ、k=10、候选集合是在开发种子上选的(赢家诅咒);确认只看新种子。
- 所有负面结果只是"本实现、本 schedule 没有增益",不是"不可能"。
