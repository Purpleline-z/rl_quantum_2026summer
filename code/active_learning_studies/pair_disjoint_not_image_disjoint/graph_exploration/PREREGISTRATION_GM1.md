# 预注册 GM1:图正则增益的机制确认(写于任何确认种子 8100–8134、8150–8184 的结果之前)

分支 `claude/graph-mechanism-20261013`。开发方案见 `PREREGISTRATION_GM0_development_plan.md`;开发结果(种子 8000–8019,6 轮共 **49 个变体**,全部列在 `RESULTS_graph_mechanism.md`,含失败的)只用于设计,有赢家诅咒,不当证据。开发中最后几轮是在前几轮看到的结果上追加的(计划写 4 轮,实际 6 轮:加了 λ/k 扫描、按类型开关、LDA 拓扑),这一点在结果文档里如实写明。

## 1. 要回答的两个声明(分别判定)
- **(a) 图质量剂量-响应**:图的质量越低(把拓扑特征加噪声,σ=0,0.5,1,2,3),增益越小。质量指标 = 理想图-理想图边中"同类占比"(`graph_quality`,每个种子、划分、图单独记录;随机水平≈0.25)。
- **(b) 新候选优于 `lap3_k10`**(新基线;`aw8_all` 只作参考行)。

## 3. 确认设计
确认 1 = 种子 8100–8134(35 个),确认 2 = 8150–8184(35 个,独立重复,单独报告,不合并)。划分 A、B;每个种子 3 次随机标注集抽样,预算 10/20/40/60;所有学习器在**完全相同的随机标注集**上配对。命令:
```
bash scripts_gm/run_gm.sh confirm1 aw8_all,lap3_k10,gm_lap3_n0,gm_lap3_n0.5,gm_lap3_n1,gm_lap3_n2,gm_lap3_n3,gm_lap10_n0,gm_lap10_n0.5,gm_lap10_n1,gm_lap10_n2,gm_lap10_n3,gm_lap10_n0_shuf,gmc_t_no_rt13,gmc_t_no_rt13_shuf,gmc_t_no_rt13_n3,gm_noise10 8100-8134 A,B 4
bash scripts_gm/run_gm.sh confirm2 aw8_all,lap3_k10,gm_lap3_n0,gm_lap3_n0.5,gm_lap3_n1,gm_lap3_n2,gm_lap3_n3,gm_lap10_n0,gm_lap10_n0.5,gm_lap10_n1,gm_lap10_n2,gm_lap10_n3,gm_lap10_n0_shuf,gmc_t_no_rt13,gmc_t_no_rt13_shuf,gmc_t_no_rt13_n3,gm_noise10 8150-8184 A,B 4
```
单位:每个种子对预算和抽样取平均的差值;检验:双侧 Wilcoxon 符号秩(种子为单位),bootstrap 95% 区间。

## 4. 检验与成功标准
**声明 (a)(`GM1_dose_primary.json`,`gm_tables.py dosetest`)**:对每个(划分 A/B)×(指标 AUC/准确率)=4 个检验,取每个种子在五个噪声档上"相对 `aw8_all` 的增益"与"图质量"的 Spearman 相关 ρ,检验 ρ 的符号秩 p(双侧);4 个检验做 Holm。**"图质量剂量-响应被确认"当且仅当 ≥3 个检验 ρ 均值为正且 Holm p<0.05。** λ=3 的同样检验是次要家族(`GM1_dose_secondary.json`),不参与判定。限制先写在这里:噪声同时改变了边数/度,质量只在理想图-理想图边上测量;所以 (a) 说的是"这一类图质量的退化与增益下降相关",不是"最优图构造"。
**声明 (b)(`GM1_spec.json`,`gm_tables.py confirm`)**:主家族 = 2 个候选 × 2 划分 × 2 指标(AUC、准确率)= 8 个"候选 − `lap3_k10`"检验,Holm。某候选**被确认**当且仅当:(i) 它的 4 个差值(A/B × AUC/准确率)都为正;(ii) 这 4 个中 ≥3 个 Holm p<0.05;(iii) 它优于自己的打乱图对照**和**噪声图对照:对每个对照,至少一个划分里 AUC 或准确率的差值为正且未校正 p<0.05。否则只写"未确认"。
**只报告、不参与判定**:候选 − `aw8_all`(4 行)、候选 − `gm_noise10`(非图对照)、log-loss 与 HTR 准确率/HTR log-loss(每个候选相对 `lap3_k10`)、按类型/按预算的增益、各剂量档的平均质量与增益。

## 5. 事先写明的限制与纪律
- 同一批 168 个标注组,以新种子重新划分,不是新数据,Wilcoxon p 偏乐观;所有开发数字有赢家诅咒。
- 打乱图是低门槛(它本身比基线差很多);噪声图和非图对照是更有信息的,但非图对照本身很弱。
- 质量指标有局限(LDA 拓扑的"质量"是循环的:拓扑用了同样的理想图标签;PCA 白化拓扑的质量高但开发中有害)——所以质量-增益的关系只在"噪声剂量"这一个操控轴上做预注册检验。
- 不会因为结果不好而更换候选、λ、k 或家族后重跑同一批种子;新变体要用新种子(8200–8599 属别的会话,不得使用)。
