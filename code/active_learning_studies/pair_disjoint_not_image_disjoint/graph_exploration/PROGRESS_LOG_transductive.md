- Reading (development observations): (1) the graph with future frames is what helps: BASE → STD (future non-test frames in the graph) gives FB AUC +0.012, FA ≈ 0; adding the test images themselves (trans_fut vs STD) a further +0.003–0.004. (2) causal transduction `trans_win` (frames that exist when the window is scored): FB AUC +0.021 / acc +0.022 / anchor-far AUC +0.064; FA AUC ≈ 0, acc +0.006. (3) `trans_test` (past + test images only) is the one that helps FA (AUC +0.006, acc +0.015). (4) SP (test-time propagation): in-graph propagation does ~nothing (±0.002), attach-smoothing on the inductive graph gives FB AUC +0.009 but costs accuracy (−0.007…−0.012). (5) TW (recency weights): null (±0.002). (6) CT (pseudo-label co-training): FB +0.009, FA −0.007. (7) Shuffled graphs are very harmful (−0.13 AUC), so "beats shuffled" is easy; graph-free transductive controls (C:, LC:) added in dev3.
- **dev3** (12 learners; also 20 seeds): L:trans_win:f0.5 (focus: half of the sampled Laplacian edges touch the images about to be scored) (+ :l10, :shuf), AQ:trans_win:r0.3:f0.5, AQ:trans_win:r0.1, AQ:trans_win:r0.3:l10, LC:trans_win:c0.3, C:trans_win:c0.3 (graph-free control), C:ind:c0.3, L:trans_test:f0.5, AQ:trans_test:r0.3. Reading: (a) the **graph-free** consistency control on the same nodes gets FB AUC +0.012 (≈ 60 % of the graph version's +0.021) but costs accuracy (FA −0.027, FB −0.005): the graph adds ≈ +0.009 AUC and ≈ +0.027 accuracy over graph-free; (b) focus does not help (FA AUC −0.001/+0.003, FB +0.014/+0.004); (c) λ = 10 helps FB slightly (+0.023 AUC) and costs FA accuracy; (d) AQ with the posterior propagated to the scored frames: FA acc +0.015 / FB +0.022 (trans_win), the best 4-cell profile so far (AQ:trans_win:r0.3:l10: FA AUC +0.004, FA acc +0.009, FB AUC +0.021, FB acc +0.022); (e) LC adds nothing over L.
- Mechanism audit (`td_mechanism.py`, dev, L:trans_win vs BASE, per judgment): the gain sits where the scored images are far (> ≈ 0.1 cosine distance, top quartile) from every past node (Δacc +0.06…+0.07) or where a not-yet-labelled future frame is closer than any past node (FA Δacc +0.049 vs −0.008 otherwise); judgments next to past nodes gain nothing or lose slightly in FA (Δacc −0.01…−0.03). That is the anchor-far / novelty gap the red team identified, so the transductive gain is not "more near-duplicates".
- Group-level vs seed-level uncertainty (dev, 8 comparisons): seed-level 95 % intervals exclude 0, test-group bootstrap intervals are 3–5× wider and mostly include 0 (only FB AUC of `trans_test` / `trans_fut` just excludes 0). The seed-level Holm tests of the pre-registration only describe training variability on fixed groups; this is reported next to every table.
