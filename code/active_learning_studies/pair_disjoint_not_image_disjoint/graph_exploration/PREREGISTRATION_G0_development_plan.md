# G0: development plan of the graph-augmented learner study (written before any development cell was run)

Branch `claude/graph-learner-20261012` (from `claude/integration`). Rules: `prompts/COMMON_RULES.md`, `prompts/PROMPT_1_graph_learner.md`. Reference learner: **`aw8_all`** of `new_directions/nd_learners.py` (frozen SimCLR features, the repository's loss with reference-anchor weight 8 and ALL ideal images as anchors, per-budget head schedule). Where an endpoint cannot use `aw8_all` (type accuracy of the outer-test ideal images) the reference is `aw8`; that endpoint is not part of this study.

## Seeds
Development 7000-7019 (the only seeds used to design and screen); confirmation 1 = 7100-7134; confirmation 2 (if time) = 7200-7234; cold-start confirmation (if time) = 7300-7334. All four blocks are added to `nd_core.USED_SEEDS_BY_EARLIER_WORK` and asserted disjoint from everything used before (`nd_core.GL_*`, tested in `test_graph_learner.py`).

## Protocol extension (the only change to the protocol)
The learner may use the unlabelled SimCLR features of every trajectory image and every ideal image to build a cosine kNN graph (features centred on the node mean and L2-normalised; k fixed at 10, swept over {5, 10, 20} on development seeds; symmetric union of the k-nearest-neighbour relation; row-normalised adjacency with self loops). **Excluded from the node set** (by SHA-256 content hash): every image of the seed's validation and test pair groups and the seed's outer-test ideal images. Images that are not nodes (test images that must be scored, outer-test ideal images used as anchors) attach to their k nearest nodes and never alter the node embeddings. Label sources for the class posterior: the training-reference and utility-validation ideal images (their class labels are in the learner's anchor set anyway); outer-test ideals are not nodes and not sources. Everything else equals `aw8_all`.

## Variants screened on the development seeds (graph kNN built per seed and split; paired with `aw8_all` on identical random label sets, budgets 10 / 20 / 40 / 60, splits A and B, 3 draws)
1. `lap<L>_k<K>`: manifold regularisation. Added loss L x mean over 256 sampled graph edges per step of sum over the four type heads of (s_k(i) - s_k(j))^2, evaluated on all nodes (labelled or not); L in {0.1, 0.3, 1, 3}, k = 10 first.
2. `rq<L>_k10`: type-posterior prior. Label spreading (alpha 0.9) of the ideal images' class one-hots over the graph gives q(x) (uniform in components without source); added loss L x weighted ranking loss on 256 random node pairs per step pulling s_k(i) - s_k(j) towards sign(q_k(i) - q_k(j)), weights |q_k(i) - q_k(j)| normalised to mean 1. Different from the rejected pseudo-labelling: the target comes from diffused reference labels, not from the model's predictions.
3. `sgc_k<K>`: the head sees Ahat X (one propagation step). `gcn2_k<K>`: two-layer graph convolution S = Ahat relu(Ahat X W1) W2 with per-type outputs, same loss.
4. Combinations of 1 + 2, 1 + sgc, 2 + sgc, gcn2 + lap (only if components show a signal).
5. Controls, run alongside the screened variants and for every winner: `*_shuf` (adjacency with permuted node identities, degree sequence kept; for the encoders the unseen images also get random neighbours), `gcn2_noedge` (identity adjacency: the same deeper network without the graph), `cons<L>` (no graph: consistency of the scores of unlabelled nodes under feature dropout 0.3, same lambda grid), `rq*_noprop` (class posterior from cosine similarity to class means, no graph).
Records: overall AUC, accuracy, log-loss and per-type metrics (HTR especially); cold start (10 random initial judgments) screened for the leading variants.

## Freezing
After the development screen I freeze at most four candidates (each with its shuffled-graph or no-graph control) and the test family in `PREREGISTRATION_G1.md`, commit it, and only then run confirmation 1 once. Success needs: some candidate with AUC and accuracy gains over `aw8_all` positive in both splits, at least 3 of the Holm-corrected tests (family = candidates x 2 splits x 2 metrics) with p < 0.05, and better than its own control (uncorrected p < 0.05 in at least one split). Otherwise the result is "not confirmed" and all variants tried are listed.
