# 一页摘要:只靠"图"吗?无标签图像上的正则化器对比(分支 `claude/regularisers-20261013`)

**问题。** 当前最好的学习器 `lap3_k10_st4` = 在无标签图像的 kNN 图上加拉普拉斯平滑项 + 4 倍训练步数。上一轮开发中,一个不用图的正则化(对输入特征 dropout 后分数应保持一致)好像能拿到大部分收益。所以要公平地问:图到底需不需要?

**做了什么。** 开发(种子 9000–9011,不算证据)筛了 20 个变体:dropout/噪声/镜像/mixup 一致性、R-Drop、隐层 dropout、权重衰减、EMA、内部划分早停、隐层拉普拉斯、最近邻(硬邻居)拉普拉斯,以及它们与拉普拉斯的组合。随后在跑任何确认种子之前冻结预注册(`PREREGISTRATION_G2.md`):3 个不用图的候选 + 1 个"图+一致性"候选 + 打乱图对照 + 调好的无图基线;确认用 35 个新种子(9050–9084)、划分 A/B、只跑一次。红队提醒:测试图像几乎都是训练帧的近重复,所以另报"远离理想图锚点"的次要终点(两张测试图到所有理想图的余弦距离都 > 0.03,每个种子只有约 12–15 个判断)。

**预先登记的确认结果。**
- **规则 A(图不需要)没有成立。** 3 个无图候选没有一个"不差于" `lap3_k10_st4`(容忍度 AUC 0.003、准确率 0.01):它们 AUC 低 0.002–0.004(区间碰到 0),准确率低 0.007–0.020。
- **规则 B(图有增益)成立,但只通过组合学习器:** "拉普拉斯 + dropout 一致性"(G1)在 AUC 和准确率上对每个无图候选都为正、且 Holm 校正后全部显著(AUC +0.003…+0.005,准确率 +0.006…+0.012);它的打乱图对照差得多(AUC −0.07/−0.08)。**单独的** `lap3_k10_st4` 没有单独满足规则 B:准确率明显更好(划分 A 上 Holm 显著),AUC 只好 0.002–0.004,区间碰到 0。
- 复核:`lap3_k10_st4` 仍显著好于调好的无图基线(AUC +0.015/+0.016,准确率 +0.020/+0.014,未校正)。
- 白话:不用图的一致性正则化能拿到约 70–90% 的 AUC 提升,但**拿不到准确率提升**(无图 −0.000…+0.007,有图 +0.014…+0.020)。图在这里确实多出一点东西,但很小;"任何无标签正则化都行"是不对的,"必须用图"也只在这个弱意义上成立。G1 并不比单独的拉普拉斯更好(AUC +0.0005/+0.0016,不显著)。

**红队提醒(次要终点,开发/描述性)。** 相对无图基线的 AUC 增益主要落在"锚点附近"的判断里(`lap3_k10_st4`:近处 +0.019/+0.020,远处 −0.001/+0.009,区间含 0);无图的一致性学习器也一样。远离理想图的判断样本太少,**无法证明图在那里有用,也不能证明没用**。

**只是开发观察(不是证据)。** EMA、权重衰减、早停、隐层 dropout、mixup(不稳定)、镜像一致性、隐层拉普拉斯、最近邻拉普拉斯都明显更差;一致性权重 3 比 0.3–1 差。

**局限。** 同一批 168 个配对组重新划分(p 值偏乐观);AUC 的非劣效性界值 0.003 与 35 个种子的标准误同量级,即使真实差为 0 也很难证明;打乱图对照只用了一半标签集(draw 0);"≤10 个变体"按每轮 ≤10 理解(共两轮 20 个)。
