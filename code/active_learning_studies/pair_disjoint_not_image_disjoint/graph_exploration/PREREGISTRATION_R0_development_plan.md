# 开发方案 R0(写于任何开发结果之前;分支 claude/representation-20261013)

**问题**:所有已确认的增益都在学习器一侧(锚点权重 8、无标注图像 kNN 图上的拉普拉斯正则、4 倍训练步数:`lap3_k10_st4`),而表示(最后一层 512 维 SimCLR 特征)从来没当过变量;图、头、锚点损失都依赖它。换一个表示能不能让 `lap3_k10_st4` 显著更好?

**基线与对照**:基线 `lap3_k10_st4`(代码与它数值一致,有测试);调好的无图对照 `aw8_all_st2lr0.5`。终点不变:留出配对组的 AUC、准确率(主要),log-loss、HTR 指标(次要);划分 A、B;预算 10/20/40/60;3 次随机标注集抽样,所有学习器在完全相同的标注集上配对(`nd_core.py`)。

**协议扩展(写进预注册)**:允许使用冻结 SimCLR 编码器的其他层、本地已有的其他冻结编码器的特征(ImageNet ResNet-18 的缓存特征,1278 张图;HuggingFace / torch hub / download.pytorch.org 经代理返回 403,**不能下载任何别的权重**)、对确定性增广(镜像、中心裁剪 + 四角裁剪,边长 90%)的特征取平均、用图的允许节点估计的中心化 + 白化 + PCA。不微调;不用验证/测试/外部测试图像或其标签;身份规则同 `nd_graph_learner.GraphData`(SHA-256)。

**开发(种子 8600–8619,至多 10 个变体 + 控制,全部与 `lap3_k10_st4` 配对)**:
1. SimCLR 第 3 层(256 维)单独 `rp_s3`;第 3 层 ⊕ 最后一层 `rp_s34`。
2. ImageNet 特征单独 `rp_i4`;ImageNet ⊕ SimCLR `rp_is`(块间 L2 归一化、不加权)。
3. 镜像平均 `rp_mir`;7 视图平均(原图、镜像、中心裁剪、四角裁剪)`rp_mc`。
4. 中心化 + 白化 + PCA 到 64 / 128 维 `rp_w64` / `rp_w128`(统计量只用图的允许节点)。
5. 图用新特征、头用旧特征:`rp_gis_hs4`(图来自 ImageNet ⊕ SimCLR);反过来:`rp_gs4_his`。
6. 控制:5 个头的集成 `rp_ens5`(免费的方差缩减);每个冻结候选再配打乱图控制 `_shuf` 和容量控制 `rp_cap`(SimCLR 最后一层 ⊕ 它的固定随机 512 维高斯投影,同样的拼接和尺度规则)。
尺度规则:单块乘以(SimCLR 最后一层的平均范数 / 该块的平均范数);拼接时每块逐图 L2 归一化后乘 平均范数/√块数,使仓库的逐预算学习率仍然合适(**学习率/步数没有为新维度重新调**,这是限制)。

**两阶段**:A 阶段用种子 8600–8609 筛 10 个变体;B 阶段用 8610–8619 对 A 阶段里 AUC 与准确率在两个划分里都不为负的 ≤5 个变体加控制复核;至多冻结 4 个候选(+控制)写入 `PREREGISTRATION_R1.md` 再跑确认(8650–8684)。开发数字有赢家诅咒,不当证据。
