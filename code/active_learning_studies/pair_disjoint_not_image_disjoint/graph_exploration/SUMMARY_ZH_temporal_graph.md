# 一页中文摘要:给拉普拉斯学习器加"时间边"有没有用?(分支 `claude/temporal-graph-20261013`)

**问题**:现在最好的学习器 `lap3_k10_st4`(调好的基线 + 在"无标注图像 kNN 图"上的拉普拉斯正则 + 4 倍训练步数)的图只由 SimCLR 特征建成。同一条生长轨迹里相邻的帧是现成的、不需要标注的结构,图没有用。这次试:把"相邻帧"的边加进拉普拉斯项(±1/±2/±5 帧、按帧距和温度差衰减、温度分箱图、只用时间的图、与 kNN 图取交集、二阶差分/曲率惩罚、只在未标注帧之间连边),并和"同一轨迹内打乱帧"的对照比。

**一句话答案:没有用。预先登记的确认实验里,三个冻结候选全部没有通过,而且没有任何一个检验在多重校正后显著。**

## 一、预先登记的确认(种子 9250–9284,划分 A、B,各跑一次;冻结文件在跑之前提交)
- 三个候选:衰减链 ±5(权重 3 和 0.3)、曲率惩罚。12 个检验里最小的原始 p = 0.066,Holm 校正后最小 p = 0.79。AUC 增益只有 −0.0005 到 +0.0018,准确率 −0.004 到 +0.0015,区间都含 0;每个候选至少有一个"应当为正"的增益不为正。
- 它们都比"打乱帧"对照好很多(AUC +0.011 到 +0.12),但这个对照很严厉(打乱后连的是长得完全不像的帧,本身就会毁掉学习器),所以只能说明"时间边不是有害噪声",不能说明时间边有用。
- **按红队要求的"远离锚点"终点:没有增益**(远离锚点的 AUC −0.019 到 +0.004)。唯一名义上为正的是"靠近锚点"那一层的 AUC(+0.003 到 +0.004,未校正,次要终点);曲率惩罚还让对数损失变差(−0.012)、HTR 准确率下降约 0.01。
- 红队的"时间分块划分"(次要终点,35 个):AUC 差别 0.0000、+0.0002、−0.0002,没有差别。**"时间边在时间分块划分上帮助最大"这个预期不成立。**

## 二、开发观察(种子 9200–9219,18 个变体,有挑选效应,不是证据)
- **84–94% 的相邻帧边本来就已经是 kNN 边**:相邻帧在特征空间里几乎是重复帧,时间边基本只是把已有的边加了权重。
- 不在 kNN 图里的那 6–16% 时间边连的是"长得不一样"的相邻帧;在它们之间做平滑会让 AUC、对数损失、远离锚点的终点都变差(我的解读,未检验:这些帧挨着表面状态的变化,得分本来就该跳变)。
- 只用时间建的图(AUC −0.02)和温度分箱图(−0.16)明显更差;把跨轨迹/时间很远的那约 4% kNN 边去掉会损失约 0.006–0.007 AUC,把它们加权则没有变化。
- **温度并不随时间单调**:三条轨迹都是先升后降(帧序号和温度的 Spearman 只有 0.30–0.63),所以物理组"温度单调演化"的假设在这里没有被用到,也没有被数据支持。

## 三、探索性补充(备用种子 9285–9299,不是预先登记)
- 确认实验里唯一的"事后线索"(温和链的远离锚点准确率 +0.008/+0.017)在新种子上**没有重复**(−0.005/+0.010)。
- 现有学习器相对调好的不用图学习器的增益**并不集中在"离已标注帧时间很近"的测试判断上**,而是集中在"靠近锚点"的判断上——这和红队分支的预先登记结论一致(不是新发现)。

## 四、需要如实说的限制
- 数据只有 3 条生长轨迹的 284 帧、同一批 168 个标注组;测试图像几乎都是训练帧的近重复。结论是"在冻结 SimCLR 特征上、35 个种子能分辨的 ±0.004 AUC 以内没有增益",**不是**"时间没有信息"。
- 红队的"时间分块"划分并不完全隔离:一个测试组里一张图在被留出的时间块内、另一张在块外时,块外那张的邻近帧仍留在图里(约 55–70% 的图节点离某张留出图像 ≤25 帧);严格的 25 帧规则在普通划分里会去掉约 98% 的时间边,所以"严格版"就等于基线。
- 同一批标注组、开发种子 20 个,p 值偏乐观;确认只有 3 个候选。

## 五、需要你做
见 `GPU_TASKS_temporal_graph.md`。最有价值的一件:给一条轨迹里连续的约 150 帧做**逐帧类型标注**(含一段转变区)——这是唯一能直接回答"相邻帧是否同类型"的数据;其次是新生长轨迹的标注配对(做真正的前瞻测试集),以及在编码器内部(端到端)加时间一致性。
