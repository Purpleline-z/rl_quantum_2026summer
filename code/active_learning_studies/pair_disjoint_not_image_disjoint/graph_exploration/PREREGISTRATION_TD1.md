# Pre-registration TD1 — transductive and forward-in-time evaluation (branch `claude/transductive-20261014`)

Frozen **before any confirmation seed was run** (development seeds 10500–10519 only; development log `PROGRESS_LOG_transductive.md`, plan `PREREGISTRATION_TD0_development_plan.md`). Machine-readable spec: `TD1_spec.json` (read by `td_confirm.py`). Confirmation 1 = seeds **10530–10564**, confirmation 2 (independent replication) = **10565–10599**; each block is run once with the frozen learners; a failed or odd run is reported, never silently rerun. Same 168 labelled pair groups as all earlier work (re-split / re-cut with new seeds, **not new data**): seed-level p-values are optimistic and only describe training variability on fixed test groups; test-group bootstrap intervals are reported next to them.

## 1. Protocol extension (new relative to every earlier study)
* **Transductive node sets** (features only, never labels). `std` = repository rule: images of validation / test groups and outer-test ideal images are not graph nodes. `trans` = std plus the images of the held-out groups as unlabelled nodes (the outer-test ideal images stay excluded).
* **Forward-in-time cuts.** Calendar axis: runs ordered by date RR220204A < RR220206A < RR220411A; an image's time = (run rank, frame number); a pair group's time = time of its later image. **168 of 168 groups can be assigned a time (0 cannot)**; 104 are cross-run pairs (assigned to the later run); 29 / 35 / 104 groups have their time in the three runs (`td_data_facts.py`, `results/td/data_facts.md`). Cut = the first n groups in calendar order are the past, n ∈ {12, 24, 40, 54, 70, 90} (two per run), n jittered by an integer in [−2, 2] chosen by the seed. Labelled = all past judgments (initial = oldest 10 past groups, the rest "revealed", which sets the head schedule exactly as in the repository), after dropping past groups that share an image with a test group (identity rule). Test windows: **FA** = next 40 groups, **FB** = following 34 groups (the test sizes of Splits A and B); decisive judgments only (≈ 56–81 per FA window, 44–70 per FB window).
* Forward node sets: `ind` (past frames + ideal images, test images excluded: deployment-inductive), `trans_test` (ind + the images of all test groups), `trans_win` (every frame that exists when the window is scored: time ≤ time of the window's last group; fitted separately per window), `trans_fut` (all frames), `std` (repository graph: future non-test frames are nodes).
* Learner family: `lap3_k10_st4` (aw8_all + Laplacian λ = 3 on the cosine kNN graph k = 10 + 4× steps; `td_core.fit_td` reproduces it bit for bit, tested) with the node set swapped; `AQ` adds the weight-0.3 type-posterior ranking loss (label spreading of the ideal-image classes over the same node set, so the posterior reaches the scored frames; `nd_graph_learner` "rq" loss, α = 0.9) on random node pairs.

## 2. Frozen candidates (4) and controls
| id | learner | what it is |
|---|---|---|
| C1 | `L:trans_win` | incumbent with the causal transductive node set (frames that exist when the window is scored) |
| C2 | `L:trans_test` | incumbent with only the scored frames added to the past graph |
| C3 | `AQ:trans_win:r0.3` | C1 + anchor posterior propagated to the scored / future frames |
| C4 | `AQ:trans_test:r0.3` | C2 + anchor posterior |
Baseline **BASE** = `lap3_k10_st4` on the inductive node set (forward: `ind`; standard / blocked: `std`). Controls: global shuffled graph (`:shuf`, node identities of the adjacency permuted), targeted shuffle (`:tshuf`, only the identities of the held-out nodes permuted, rest of the graph intact), tuned graph-free control `G0` = `aw8_all_st2lr0.5`, graph-free transductive control `C:trans_win:c0.3` (dropout-consistency of the scores of random nodes of the same node set, no edges), `AQ:ind:r0.3` (inductive version of the AQ loss), decomposition rows `STD`, `L:trans_test`, `L:trans_win`, `L:trans_fut`. In the standard / blocked splits all transductive node sets coincide (`trans`): C1 and C2 are the same learner there (`L:trans_fut`), C3 and C4 as well (`AQ:trans_fut:r0.3`).

## 3. Test family, success rule
* **Primary family (forward endpoint)**: for each of the 4 candidates, windows FA and FB × {AUC, accuracy} = **16 tests**; statistic = per-seed mean over the six cuts of (candidate − BASE) on identical labelled sets and head seeds; two-sided Wilcoxon signed-rank over the 35 seeds; **Holm over all 16**; a test counts when the gain is positive and Holm p < 0.05. Log-loss, anchor-far metrics, per-type metrics are secondary / descriptive.
* **A candidate succeeds** when ≥ 3 of its 4 tests count **and** it beats its shuffled controls on AUC in both windows (candidate − control positive, uncorrected p < 0.05): the global shuffle and, in confirmation 1, also the targeted shuffle (the targeted control is not run in confirmation 2, to save compute: the replication uses the global shuffle only; stated in advance). Success is judged in confirmation 1; confirmation 2 is the replication (same rule, independent seeds).
* **Secondary families (descriptive, own Holm, not part of the success rule)**: standard random splits A / B at budgets 10 / 20 / 40 / 60 (identical random label sets, one draw; budgets pooled): distinct standard learners × {A, B} × {AUC, accuracy} vs BASE (`std`) — "how much of the advantage is simply the test frames being in the graph"; the red-team time-blocked split (`rt_blocked`; 100-frame blocks, 25-frame buffer) likewise; anchor-far stratum (both images > 0.03 cosine distance from every typed anchor) and its complement on every endpoint.
* **Intervals**: bootstrap over seeds (4000 resamples) and test-group bootstrap (resampling the labelled groups, 1000 resamples; AUC unweighted, accuracy confidence-weighted as in the endpoint). The number of test judgments per window and cut is reported (forward windows are small); the group-level interval is the honest one for generalisation to new groups.
* **Say honestly** if a gain exists only near anchors (anchor-near stratum) and when it exists only on one window.

## 4. What development (seeds 10500–10519, 20 seeds × 6 cuts for the forward screens, 20 seeds × 2 splits × 4 budgets for the standard screen) showed, and what was tried
Everything tried is listed (names as in `td_learners.py`): L:trans_test, L:trans_fut, L:trans_win (+ `:l10`, `:l30`, `:f0.5` focus, `:shuf`, `:tshuf`), STD, G0, SP (test-time score propagation: `SP:ind:ind:a{0.3,0.5,0.7,0.9}` attach-smoothing on the inductive graph, `SP:ind:trans_fut:a{0.3…0.9}`, `SP:trans_test:ind:a0.5`, `SP:trans_fut:trans_fut`, `SP:trans_win:trans_win`), TW (recency weights τ = 10 / 30 / 100 groups), AQ (`AQ:ind:r1`, `AQ:trans_fut:r{0.3,1}`, `AQ:trans_win:r{0.1,0.3}` with `:l10`, `:f0.5`, `AQ:trans_test:r0.3`), CT (pseudo-label co-training, `CT:trans_fut:n100:m1.0`, `CT:trans_win:…` partial), LC / C (graph-free consistency controls). Development reading (not evidence): transductive node sets help the far window and the anchor-far / novel judgments (mechanism audit), the near window much less; the graph-free control gets ≈ 60 % of the AUC gain but not the accuracy gain; test-time propagation, recency weights and co-training do not give a consistent gain and are **not carried** into the confirmation; shuffled graphs are strongly harmful so "beats shuffled" is a weak statement (hence the targeted control and the graph-free control); on the standard random split the test frames being in the graph adds only ≈ +0.003 AUC. λ = 10 variants look slightly better but were not frozen to keep the comparison with BASE (λ = 3) free of a λ confound.


Inductive reference learners (dev5; same 20 seeds × 6 cuts): `AQ:ind:r0.3` −0.002 / −0.003 AUC (FA / FB), no accuracy gain (the AQ loss alone does not help); `L:ind:l10` (λ = 10, inductive) +0.001 / +0.004 AUC, accuracy ±0.004 (so the transductive gains of the λ = 3 candidates are not a λ effect). Candidate profiles over (FA AUC, FA acc, FB AUC, FB acc) vs BASE in development (20 seeds, seed-level, optimistic): C1 `L:trans_win` −0.001 / +0.006 / +0.021 / +0.022; C2 `L:trans_test` +0.006 / +0.015 / +0.012 / +0.006; C3 `AQ:trans_win:r0.3` +0.002 / +0.015 / +0.017 / +0.022; C4 `AQ:trans_test:r0.3` +0.007 / +0.014 / +0.012 / −0.001. Test-group bootstrap intervals of these gains are 3–5 times wider than the seed-level ones and mostly include 0. Re-running a learner in a different result directory reproduces its metrics exactly (checked, max |ΔAUC| = 0), so cells are deterministic given (seed, cut, learner). The candidates were chosen as the two node-set choices (causal `trans_win`, minimal `trans_test`) × {Laplacian only, + anchor posterior}, not as the best-looking cells, and λ was not tuned.
