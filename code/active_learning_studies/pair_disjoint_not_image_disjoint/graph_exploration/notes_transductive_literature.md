# Literature notes — transductive / forward-in-time (2026-10-14; only what the search results state, marked "(摘要)")

- Gradual self-training (Kumar, Ma, Liang, ICML 2020, PMLR 119:5468–5479) (摘要): adapting a source-trained classifier with unlabelled data that drifts gradually towards the target; the algorithm pseudo-labels each intermediate domain and retrains with regularisation; the stated bound is non-vacuous under gradual shift and works best when consecutive shifts are small; regularisation and label sharpening remain essential. Relevance: the forward protocol is a gradual shift (frames of a run follow each other); the "co-training on unlabelled future frames" variant (CT) is the simplest instance. Caveat: pseudo-label self-training on this dataset was a confirmed null in the earlier (random-split) work.
- Transductive label propagation in few-shot learning (TPN, ICLR 2019, arXiv 1805.10002; prototype-based label propagation CVPR 2023, arXiv 2304.11598; ECALP 2024, arXiv 2412.18303) (摘要): classify the whole query set jointly through a graph over query + support samples; the TPN authors report that plain label propagation without learned propagation already beats most baselines; ECALP adds graph expansion so that streams of test samples can be handled inductively. The search results contain no direct measurement of "how much of the gain is just the test points being in the graph", which is what the secondary endpoint here measures.
- Forward chaining for temporal data (Bergmeir & Benítez 2012, cited by a reading list; blogs) (摘要): random splits can put future observations in the training set and give optimistic estimates; train on the past, test on a later period. Here: random splits already let test images have near-duplicate training frames on both sides in time, forward splits do not.
