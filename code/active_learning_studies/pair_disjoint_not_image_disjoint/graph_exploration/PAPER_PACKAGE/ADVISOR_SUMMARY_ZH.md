# 一页中文摘要(给导师):结果包——哪些结论经得起检验

*所有数字都带标记,由 `check_prose.py` 对照脚本生成的表格逐个核对;完整表格见 `tables/`,图见 `figures/`,逐条结论与证据见 `tables/claims_table.md`。*

**数据与口径(先说清楚)。** 全部实验基于同一批 168 个标注配对组(521 条判断,284 张图,来自 3 次生长);"新种子"只是把这批数据重新随机划分,不是新数据,所以 p 值偏乐观。只有**事先登记、在没用过的种子上只跑一次**的确认才算证据(每个确认块 35 个种子,冷启动块 15 个;划分 A / B 两种);其余都只是开发观察。下面所有"增益"都是留出配对判断的 AUC / 准确率之差,对同一批随机标注集配对比较,A / B 为两种划分。

## 一、预先登记并已确认的(规则事先冻结)
1. **参考图排序损失权重 0.25 → 8**:AUC +0.012 / +0.019,准确率 +0.019 / +0.023;把全部理想图当锚点:AUC +0.020 / +0.023。
2. **在无标注图像的余弦 kNN 图上加拉普拉斯正则**(相邻图像得分拉近):比 aw8_all 的 AUC 高 +0.015 / +0.014,两个独立块和冷启动都重复出来。
3. **训练步数 ×4**(现在的最佳学习器 lap3_k10_st4):比上一版再高 AUC +0.010 / +0.007;比"调过日程的无图对照"(aw8_all_st2lr0.5)高 AUC +0.021 / +0.016、准确率 +0.023 / +0.020(主检验,独立块与冷启动均重复)。
4. **选择规则只对弱学习器有用**:默认头下 vopt_u 比随机选 AUC 高 +0.010 / +0.013;换成最佳学习器后,四条预登记的选择规则**都没有**优于随机(vopt_u:+0.001 / −0.001)。
5. **图的质量确实有关系**:图被噪声破坏得越厉害增益越小(增益与图质量的逐种子 Spearman 相关 +0.76 / +0.67,两个块都确认)。

## 二、没有确认 / 不能这样说的
- **HTR(实验室最关心的类型)**:aw8_all 相对默认头的 HTR 增益没有确认(12 个预登记检验 0 个显著);最佳学习器相对调过的无图对照,HTR 规则只在一个块通过,不稳健。
- **"打乱图对照更差"是个很低的门槛**:打乱的图比完全不用图还差得多(AUC −0.128 / −0.126),所以"赢过打乱图"不能证明图结构本身的作用。开发观察里,不用图的一致性正则在同样长日程下只差 −0.005 / −0.007 AUC。
- **"无标注图像越多越好"不成立**:形式检验通过,但增益只来自"图里从没有轨迹帧到有 10% 的帧"这一步,之后没有继续上升。
- **论文自己的终点(28 张理想图的类型准确率)**:没有图方法能稳定赢过最近邻;唯一达标的那个块里,增益大部分是普通逻辑回归本身比最近邻高 +0.021,拉普拉斯逻辑回归只再多 +0.004(不显著),不是图的功劳;拉普拉斯奖励头反而显著更差。

## 三、红队警告(最重要的保留;红队的确认块,35 个没用过的种子)
留出判断里,47% 有一张图与某张带类型标签的理想图(锚点)几乎一模一样(余弦距离 ≤ 0.001)。最佳学习器相对调过的无图对照,AUC 增益在这类"锚点近邻"判断里是 +0.035 / +0.037;在离最近锚点 0.01 到 0.03 的中间带约为零(−0.002 / −0.002);在两张图都离所有锚点超过 0.03 的"锚点远离"判断里又回到 +0.019 / +0.013(准确率 +0.029 / +0.029)。如果像红队自己那样把"远离"定为 0.01 以上,AUC 增益只剩 +0.003 / +0.001。所以:增益**不是只靠"抄近邻"**,但分布不均匀,而且"远离"的门槛定在哪里会改变结论;锚点远离的判断只占约 22%,区间很宽。分开看:拉普拉斯正则本身相对 aw8_all 在锚点远离时仍为正(AUC +0.013 / +0.027);"步数 ×4"的额外增益主要在锚点近邻(+0.021 / +0.018),锚点远离时是 +0.012 / −0.001(区间含 0);最早的锚点权重增益在锚点远离时同样大(AUC +0.020 / +0.034),不是"抄近邻"的假象。

另一方面,按时间分块留出(把留出块周围 25 帧的缓冲区从训练组、候选池和图里去掉)时增益仍在:AUC +0.026,准确率 +0.012(来自开发审计)。

## 四、赢家诅咒与下一步
开发种子上挑出的方法,到确认种子上增益中位数缩到开发的 0.93 倍(范围 0.50 到 2.42)。结论都只对"冻结 SimCLR 特征 + 这 168 组数据"成立。**决定性的下一步**:用新的生长轨迹做一批前瞻性标注,作为固定测试集(见 `GPU_TASKS_paper_package.md`)。
