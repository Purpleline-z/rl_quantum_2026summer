# Draft abstract-level summary (English)

*Every number carries a marker that names its key in `tables/numbers_*.json`; `check_prose.py` fails if a number does not match. Status words follow the claims table (`tables/claims_table.md`).*

**Setting.** We study how well a reward model trained on a few pairwise (pair, type) judgments predicts held-out judgments of RHEED reconstruction types, with frozen SimCLR features and 10 to 60 added judgments. All experiments use one small data set: 168 labelled pair groups (521 judgments) over 284 frames of 3 growth runs; every "new seed" is a new random re-split of these same groups, so p-values are optimistic and only pre-registered confirmations on unused seeds count as evidence.

**What was confirmed (pre-registered, 35 unused seeds per block, splits A / B).** (i) Raising the weight of the reference-anchor loss from 0.25 to 8 improves held-out AUC by +0.012 / +0.019 over the default head; using all ideal images as anchors gives +0.020 / +0.023. (ii) A Laplacian regulariser on a cosine-kNN graph of unlabelled frames adds +0.015 / +0.014 AUC on top of the anchor-weighted learner (replicated in an independent block and from a cold start), and training the head for four times as many steps adds a further +0.010 / +0.007. (iii) The resulting learner beats a graph-free learner whose schedule was tuned by +0.021 / +0.016 AUC and +0.023 / +0.020 accuracy (primary test; replicated). (iv) Acquisition rules matter only for a weak learner: pool-wide variance-reduction selection beats random selection with the default head (AUC +0.010 / +0.013), but with the best learner no pre-registered rule does (vopt_u: +0.001 / −0.001 AUC).

**What the graph does and does not explain.** The gain of the graph regulariser falls as the graph is corrupted (per-seed Spearman between gain and graph quality +0.76 / +0.67, confirmed in two blocks); a shuffled graph is far worse than no graph (AUC −0.128 / −0.126 against the baseline), so beating a shuffled control is a low bar. In development a graph-free consistency regulariser at the same long schedule comes within −0.005 / −0.007 AUC of the best learner, so the graph's own share is small and unconfirmed. Adding unlabelled frames helps only up to about 10% of the trajectory frames (the formal trend test passes, the plateau check says more frames do not help).

**Limits that change how the results should be read.** Held-out frames are near-duplicates of training frames, and 47% of held-out judgments involve an image within cosine distance 0.001 of a typed ideal image. On the red team's confirmation block (35 unused seeds) the gain of the best learner over the tuned graph-free control is +0.035 / +0.037 AUC for these anchor-near judgments, about zero in the bands 0.001 to 0.03 from the nearest anchor (−0.002 / −0.002 at 0.01 to 0.03), and +0.019 / +0.013 AUC (accuracy +0.029 / +0.029) where both images are farther than 0.03 from every anchor; with the red team's own stricter far threshold of 0.01 the AUC gain is only +0.003 / +0.001. So the gain is not confined to near-copies of anchors, but it is uneven and the verdict depends on where "far" starts. The pieces differ: the Laplacian regulariser's gain over aw8_all stays positive anchor-far (+0.013 / +0.027 AUC), the extra gain of the longer schedule is anchor-near (+0.021 / +0.018 there, +0.012 / −0.001 anchor-far with intervals that include zero), and the anchor-weight gain is as large anchor-far (AUC +0.020 / +0.034). A time-blocked split that removes a 25-frame buffer around held-out blocks of a run keeps the gain (development audit: AUC +0.026, accuracy +0.012). Development gains shrank on confirmation seeds by a median factor of 0.93 (range 0.50 to 2.42). A prospective test on new growth runs is the decisive next experiment.
