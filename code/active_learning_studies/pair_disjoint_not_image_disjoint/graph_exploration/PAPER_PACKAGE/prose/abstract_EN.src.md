# Draft abstract-level summary (English)

*Every number carries a marker that names its key in `tables/numbers_*.json`; `check_prose.py` fails if a number does not match. Status words follow the claims table (`tables/claims_table.md`).*

**Setting.** We study how well a reward model trained on a few pairwise (pair, type) judgments predicts held-out judgments of RHEED reconstruction types, with frozen SimCLR features and 10 to 60 added judgments. All experiments use one small data set: 168⟦data.pair_groups⟧ labelled pair groups (521⟦data.judgments⟧ judgments) over 284⟦data.images⟧ frames of 3⟦data.sessions⟧ growth runs; every "new seed" is a new random re-split of these same groups, so p-values are optimistic and only pre-registered confirmations on unused seeds count as evidence.

**What was confirmed (pre-registered, 35 unused seeds per block, splits A / B).** (i) Raising the weight of the reference-anchor loss from 0.25⟦-⟧ to 8⟦-⟧ improves held-out AUC by +0.012⟦cl.L1.A.auc.gain⟧ / +0.019⟦cl.L1.B.auc.gain⟧ over the default head; using all ideal images as anchors gives +0.020⟦cl.L2.A.auc.gain⟧ / +0.023⟦cl.L2.B.auc.gain⟧. (ii) A Laplacian regulariser on a cosine-kNN graph of unlabelled frames adds +0.015⟦cl.L3.A.auc.gain⟧ / +0.014⟦cl.L3.B.auc.gain⟧ AUC on top of the anchor-weighted learner (replicated in an independent block and from a cold start), and training the head for four times as many steps adds a further +0.010⟦cl.L4.A.auc.gain⟧ / +0.007⟦cl.L4.B.auc.gain⟧. (iii) The resulting learner beats a graph-free learner whose schedule was tuned by +0.021⟦cl.L5.A.auc.gain⟧ / +0.016⟦cl.L5.B.auc.gain⟧ AUC and +0.023⟦cl.L5.A.acc.gain⟧ / +0.020⟦cl.L5.B.acc.gain⟧ accuracy (primary test; replicated). (iv) Acquisition rules matter only for a weak learner: pool-wide variance-reduction selection beats random selection with the default head (AUC +0.010⟦cl.S1.A.auc.gain⟧ / +0.013⟦cl.S1.B.auc.gain⟧), but with the best learner no pre-registered rule does (vopt_u: +0.001⟦cl.S3.A.auc.gain⟧ / −0.001⟦cl.S3.B.auc.gain⟧ AUC).

**What the graph does and does not explain.** The gain of the graph regulariser falls as the graph is corrupted (per-seed Spearman between gain and graph quality +0.76⟦cl.G1.A.auc.rho⟧ / +0.67⟦cl.G1.B.auc.rho⟧, confirmed in two blocks); a shuffled graph is far worse than no graph (AUC −0.128⟦cl.G3.A.auc.gain⟧ / −0.126⟦cl.G3.B.auc.gain⟧ against the baseline), so beating a shuffled control is a low bar. In development a graph-free consistency regulariser at the same long schedule comes within −0.005⟦cl.D2.A.auc.gain⟧ / −0.007⟦cl.D2.B.auc.gain⟧ AUC of the best learner, so the graph's own share is small and unconfirmed. Adding unlabelled frames helps only up to about 10%⟦-⟧ of the trajectory frames (the formal trend test passes, the plateau check says more frames do not help).

**Limits that change how the results should be read.** Held-out frames are near-duplicates of training frames, and 47%⟦af.anc_all_min.near<=0.001⟧ of held-out judgments involve an image within cosine distance 0.001⟦-⟧ of a typed ideal image. In a red-team audit (20⟦-⟧ development seeds, not a confirmation) the gain of the best learner over the tuned graph-free control is +0.035⟦cl.R1.A.near<=0.001.gain⟧ / +0.028⟦cl.R1.B.near<=0.001.gain⟧ AUC for these anchor-near judgments, but +0.016⟦cl.R1.A.far>0.03.gain⟧ / +0.021⟦cl.R1.B.far>0.03.gain⟧ where both images are farther than 0.03⟦-⟧ from every anchor, with intervals that touch or include zero; the earlier anchor-weight gain does not have this problem (anchor-far AUC +0.044⟦st.dev.aw8_all.baseline.A.far>0.03.auc.gain⟧ / +0.035⟦st.dev.aw8_all.baseline.B.far>0.03.auc.gain⟧). In the same audit the gain survives a time-blocked split that removes a 25⟦-⟧-frame buffer around held-out blocks of a run (AUC +0.026⟦cl.R3.auc.gain⟧, accuracy +0.012⟦cl.R3.acc.gain⟧). Development gains shrank on confirmation seeds by a median factor of 0.93⟦wc.ratio_median⟧ (range 0.50⟦wc.ratio_min⟧ to 2.42⟦wc.ratio_max⟧). A prospective test on new growth runs is the decisive next experiment.
