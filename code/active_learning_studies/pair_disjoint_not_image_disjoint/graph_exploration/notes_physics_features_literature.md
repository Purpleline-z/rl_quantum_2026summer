# Literature notes: physics-informed RHEED features (branch claude/physics-features-20261014)
WebSearch only (arXiv/CVF blocked); every item is from the search result text and marked "(abstract/snippet)"; nothing was read in full.
- PNNL / J. Vac. Sci. Technol. A 43(3) 032702 (2025), "Machine-learning-enabled on-the-fly analysis of RHEED patterns during thin film deposition by MBE" (abstract/snippet): frames featurised with a *pretrained CNN*, changepoint detection and graph/community classification; a CNN separates "streaky" from "spotty" β-Ga2O3 patterns. Appearance features, as in this project.
- NIST-hosted paper "Application of machine learning to reflection high-energy electron diffraction images ..." (snippet): U-Net segments spots/streaks, then the horizontal *spacings between features* serve as a fingerprint to tell crystal phases apart, analysis restricted to a window around the zero-order Laue circle. This is the closest published analogue of the "spacing-based" descriptors built here.
- Atomscale RHEED documentation (snippet): per-feature metrics FWHM, eccentricity, streak-vs-spot area; PCA + clustering on time series. k-Space kSA 400 (snippet): streak-spacing monitoring for strain. Commercial tools; no accuracy numbers seen.
- AIP Advances 16, 035317 (2026), CNN classification of RHEED patterns for chalcogenide growth (snippet): >98 % for dot nucleation vs 2D growth, lower accuracy for modulated streaks, attributed to label ambiguity.
- PyRHEED (GitHub yux1991, snippet): line-profile fitting with Gaussian/Voigt peaks, simulation modules; open source line-profile analysis exists for RHEED, none found that targets *reconstruction-type* preference learning.
- SrTiO3(001) reconstructions: Applied Physics Letters 105, 191901 (2014) "Surface reconstructions in molecular beam epitaxy of SrTiO3" (abstract/snippet): reconstructions correlate with a change from mixed SrO/TiO2 to TiO2 termination, visible as a phase shift of RHEED oscillations; c(6x2) structure from combined X-ray / electron diffraction and first-principles screening (snippet); a surface-X-ray study of single-terminated (1x1) crystals found *no fractional-order reflections* in RHEED or SXRD (snippet) — consistent with "(1x1) = integer rods only". The search found no source for the root13 x root13 R33.7 assignment (unconfirmed here).
- What was NOT found: any study using hand-built diffraction descriptors as the input of a preference / reward model, or a study of whether physics descriptors help semi-supervised graph regularisation. The design here is therefore empirical.
