# GPU / lab tasks left for the user — latent-type study

The CPU study is finished (see `RESULTS_latent_type.md`). What it could not settle, and what needs GPU or lab time:

1. **Ground truth for the latent model (lab, ~1–2 h, no GPU).** The confusion table T and the posteriors of the judgment images are validated only indirectly (leave-anchors-out on ideal images; control comparisons). Give absolute type labels (as for the 150 ideal images) to ≈ 100 trajectory frames that appear in labelled judgments (any 100 of the 284 frames of the 168 pair groups; cost ≈ 100 labels ≈ 200 judgments by the first-30-anchors exchange rate). Then (a) estimate the true confusion table from the judgments + labels and compare it with the EM table (tie 0.6–0.7 when both images are of type k, not_apply 0.04–0.06; typed image wins 0.73–0.81 when exactly one is; not_apply ≈ 0.6 when neither is); (b) measure the accuracy of the posterior memberships of these frames directly. This is the experiment that decides whether the posterior is worth more than the graph prior for real trajectory frames.
2. **End-to-end fine-tuning with the latent-type auxiliary target (GPU, ≈ 1 GPU-day).** All head-side uses were tested on frozen SimCLR features (auxiliary cross-entropy to the posterior, soft pseudo-anchors, answerability weighting) and moved AUC by ≤ 0.003 in the standard endpoint. If the encoder is fine-tuned, an auxiliary type target from the posteriors could change the representation, which the frozen head cannot do. Same protocol (A/B splits, 35 new seeds ≥ 10800, `lap3_k10_st4` as baseline, prior-only control mandatory).
3. **New growth run, leave-a-run-out (GPU/lab).** Both the near-anchor structure (test frames are near-duplicates of training frames) and the 168 pair groups limit what any head-side change can show; the anchor-far stratum is where a membership model should matter and where the data are scarcest. A fourth run with a few hundred new judgments, all arms evaluated leave-a-run-out, is the clean test (see also `GPU_TASKS_redteam.md`).
4. **More judgments per image (lab).** EM posteriors exist only for the ≤ 100 images that occur in labelled judgments and change the leave-anchors-out type recovery by < 1 point; a protocol that repeats several types / several partners for the same image (so that each image gets 3–4 outcomes) would give the likelihood much more to work with. The judgments of one image pair for several types already form one factor; that is the only coupling present in the current data.
5. **Selection (not tested here).** The model gives, for every unlabelled pair, the expected information about memberships; using it to choose which judgment to ask next is an obvious follow-up, but earlier selection studies found no gain under the strong learners, so only worth doing together with item 4.
