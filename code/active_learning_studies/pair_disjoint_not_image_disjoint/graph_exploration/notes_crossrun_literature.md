# Literature notes — adapting to a new run with few labels (study CR)

Only what the search snippets say (marked "(snippet)"); arXiv/CVF are not readable in full text here.

- **L2-SP** (Li, Grandvalet, Davoine, ICML 2018, "Explicit Inductive Bias for Transfer Learning with Convolutional Networks"): weight decay pulls parameters towards zero, which is a poor fit for fine-tuning; an L2 penalty with the *pre-trained (source) weights* as reference keeps source features and consistently beat plain L2 fine-tuning on three image benchmarks (snippet). This is the `cr_ft` learner (weight-space shrinkage to the source head).
- **Importance weighting under covariate shift** (reviews / lecture notes, snippets): reweight source examples so that their covariate distribution matches the target; the variance of the weighted loss grows with the chi-square divergence between source and target, so weighting helps little when overlap is poor (an inference from the cited statement). The same results note that adding irrelevant (less relevant) source domains can hurt generalisation (negative transfer). This is the `cr_iw` learner, and the reason `cr_pool` can lose to `cr_tgt`.
- **Semi-supervised domain adaptation**: Saito et al., "Semi-Supervised Domain Adaptation via Minimax Entropy" (ICCV 2019): standard unsupervised DA degrades when even a few target labels exist; an entropy-based adversarial scheme on the unlabelled target data is proposed (snippet). Not implemented here (needs a classifier; our head is a pairwise scorer); noted as a possible GPU-side variant.
- **Label propagation** for transductive few-shot / semi-supervised learning (Liu et al. TPN; Iscen et al. CVPR 2019) pseudo-labels unlabelled points through a similarity graph (snippets); our `cr_gprop` propagates the *source head's scores* from the source frames to the new run's frames over the kNN graph and uses them as a function-space prior. Shuffled-graph propagation is the control.
- **Not found**: a direct comparison of source-only / target-only / pooled / fine-tuned training with about 5–40 target labels on a scorer trained with typed anchors; the comparison here is empirical, on three growth runs.
