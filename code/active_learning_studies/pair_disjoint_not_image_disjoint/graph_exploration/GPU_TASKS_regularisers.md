# GPU / user tasks left by the regularisers (G2) branch

All CPU experiments used frozen SimCLR features and the one-hidden-layer MLP head; "augmentation" could only be feature dropout / Gaussian noise / mirror features. Not run, and needing a GPU (or the user):

1. **Real image-space augmentation consistency in the end-to-end model** (Mean-Teacher / FixMatch style: random crops, brightness/contrast, small rotations of the RHEED images, EMA teacher) on all trajectory frames, combined with the Laplacian term and the 4× schedule. Feature-space dropout/noise consistency recovered most of the AUC gain of the Laplacian but not its accuracy gain; image-space consistency is the standard stronger form and cannot be tested on frozen features.
2. **Laplacian + consistency (G1, `rglap3_cons0.3_k10_st4`) in the end-to-end model**, with the shuffled-graph control: G1 was the only learner that passed the pre-registered "graph adds" rule, but it is not better than the plain Laplacian (`lap3_k10_st4`) in the descriptive comparison.
3. **A test set far from the anchors.** The red-team audit shows ≈ 39 % of held-out judgments involve an image within cosine distance 0.001 of a typed ideal image; only ≈ 12–15 judgments per seed and split are anchor-far (> 0.03). To decide whether any unlabelled-image regulariser helps for images far from every ideal image, label **new independent growth runs** (or a few hundred pair judgments whose images are all far from the ideal images) and evaluate the learners `aw8_all_st2lr0.5`, `lap3_k10_st4`, `rgcons0.3_st4`, `rglap3_cons0.3_k10_st4` on them once, with the graph built only from the earlier runs.
4. **Time-blocked / run-blocked evaluation of the graph-free learners** (the red-team time-blocked and harsh-split tools exist in `rt_blocked.py` and `ge_harsh.py` of the sibling branches; I did not run the new learners through them).
5. User decision: whether the default learner of the pipeline stays `lap3_k10_st4`, becomes `rglap3_cons0.3_k10_st4`, or the paper claim is worded as "an unlabelled-image regulariser helps, the graph adds a small amount on accuracy" (I did not touch `code/ACADEMIC_REPORT_DRAFT.md`).
