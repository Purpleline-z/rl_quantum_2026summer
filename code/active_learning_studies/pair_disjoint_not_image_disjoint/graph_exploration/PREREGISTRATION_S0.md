# PREREGISTRATION_S0 — development plan (Prompt 2, written 2026-10-12 before any development result)
Branch `claude/graph-selection-htr-1012`. Learner for all comparisons: `aw8_all` (anchor weight 8, all 144 ideal images as anchors; the tuned learner of `new_directions`). Protocol unchanged (judgment-unit, budgets 10/20/40/60, splits A/B, single-shot selection from the model trained on the 10 initial groups; Random = 3 draws; held-out decisive-judgment prediction). Harness: `new_directions/gsel_select.py` (+ `gsel_analyze.py`).
Seeds: development 8000–8019 (20), confirmation 1 = 8100–8134, confirmation 2 (cold start, `ND_INITIAL=random`) = 8200–8234, confirmation 3 (HTR rule) = 8300–8334; all registered as used in `nd_core.USED_SEEDS_BY_EARLIER_WORK`.

## Dev stage 1 (frozen rules, no tuning): `tdc`=typed_decisive_coverage, `tdc_typeonly`, `tdc_shuffled`, `tcu`=typed_coverage_uniform, `vopt_u`, `vopt_u@aw` (selection model fitted with aw8_all), `gvopt_lap3` (+`@aw`), `gvopt_lap3_shuffled@aw`; regular and cold start. Purpose: see whether any frozen rule keeps a gain over Random under `aw8_all`. Prior (from `new_directions`): `vopt_u` gain vanishes under aw8; none of 30 earlier strategies beat random on dev seeds after correction; I therefore expect little or nothing, and say so before looking.
## Dev stage 2 (mechanism): type composition of batches (share of t1x1/tc6x2/t13/htr, unique images) vs Random; a type-quota variant of coverage to test whether the type allocation is the active ingredient.
## Dev stage 3 (HTR rules, <= 8 variants, each with a shuffled-graph control): `htr_amb` (rank HTR/RT13 judgments by label-spreading ambiguity r=q_HTR/(q_HTR+q_RT13), 1-|2r-1|), `htr_bridge` (min(q_HTR,q_RT13)), `htr_cov_amb`, `htr_cov_bridge` (typed coverage x node weight x P(decisive)), `htr_vopt_amb@aw`, `htr_vopt_bridge@aw` (vopt_u with target weights). Variants beyond these are listed in the final document as "added after seeing dev results".
## Freeze rule: at most 4 candidates (including the matching controls counted separately), written to `PREREGISTRATION_S1.md` and committed before any seed >= 8100 is run. Success criteria exactly as in the prompt: (A) AUC and accuracy gains over Random Holm-significant in both splits at cold start or regular budget, graph claims must also beat the shuffled control; (B) HTR accuracy and AUC gains Holm-significant, other-type accuracy loss <= 0.01.
