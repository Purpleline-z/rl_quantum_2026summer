# 一页中文摘要:用模拟器生成"合成类型锚点"有没有用?(分支 `claude/synthetic-anchors-20261014`)

**问题**:带类型的锚点(理想图)最稀缺。能不能用模拟器给图像空间的每个区域造出无限多合成锚点,让学习器在"远离真实锚点"的留出判断上也变好?
**说明**:仓库里的模拟器压缩包(p656,2250 张)在本环境里**找不到**,所以我自己写了一个**运动学**RHEED 模拟器(只算单次散射:倒易杆 × Ewald 球、域大小造成的条纹宽度、c(6x2) 和 √13 的超晶格与畴混合、探测器噪声等;没有多重散射和结构因子)。**HTR 没有文献给出晶格,用的是任意"替身"**,关于 HTR 的任何结果都不能当物理结论。

**一句话答案:模拟器图像当锚点没有用(两次独立确认都是),它的图像本身没有提供任何超出"以类型均值为中心的一团点"的信息。** 真正有点用的是另一件事:真实锚点的**图像风格**。

## 一、预先登记的确认(种子 11130–11164 与 11165–11199,各 35 个,划分 A、B,各跑一次;规则在跑之前冻结)
- **没有任何候选满足预先登记的成功规则**(AUC 与准确率在两个划分上都为正,4 个检验里至少 3 个在 Holm 校正后显著,并优于对照),两次确认结果一致。
- **C3 合成锚点**:失败。AUC 只有 −0.001…+0.002,准确率 −0.001…−0.0065;与"同均值同协方差的高斯点云"对照没有区别(≤0.0005 AUC),确认 2 里也不优于"类型打乱"对照。
- **C1 距离门控**(测试对里两张图都离所有类型锚点 >0.03 时,改用"遮掉直接束斑的锚点"训练出的第二个头,否则用原来的头):**AUC 提高在两次确认里都成立**(+0.0042/+0.0037 与 +0.0033/+0.0049,四个检验 Holm 后全部显著,也优于等算力对照 +0.003…+0.005),对数损失更好约 0.008(p<1e-4,两次都是);但**准确率提高没过 Holm**(+0.0022/+0.0037;−0.0002/+0.0050),所以按规则**未确认**。
- **C2 两头平均**:标准规则没过,但预先登记的"远离锚点"家族**两次都确认**(远离锚点 AUC +0.021/+0.012 与 +0.013/+0.015,Holm p ≤0.02;远离锚点准确率 +0.01…+0.03),代价是靠近锚点那一层准确率下降约 0.004–0.005(合并 70 个种子,事后描述)。
- 红队时间分块划分(次要,未校正):C1 的 AUC 提高也在(+0.0027、+0.0071),准确率≈0;两张图都落在留出时间块内的那一层,谁都不显著。

## 二、开发观察(种子 11100–11119,约 45 个变体,有挑选效应,不是证据)
- **差距分析**:校准后,只用合成特征训练的类型分类器在真实(遮掉束斑的)理想图上准确率 61%(校准前 31%):(1x1) 33/41、c(6x2) 40/42 对得上,RT13 7/30、HTR 1/19 对不上;但"真实 vs 合成"分类器仍能**完全分开**(AUC 1.0)。
- **不用任何配对标注、只用锚点**时:真实锚点在留出偏好上 AUC 0.92–0.94,合成锚点只有 0.58–0.60(类型打乱对照 0.41–0.45)——有一点类型信息能跨过差距,但远不如真实锚点;把合成锚点混进真实锚点反而更差。
- 把合成锚点的类型均值挪到真实均值上能恢复大部分性能,**但同均值同协方差的高斯点云一样好**:有用的是"类型中心附近的散布",不是模拟器图像。
- **一个与模拟器无关的发现**:154 张理想图里有 **18 张(10 张 HTR、8 张 RT13)是 16 位 PNG,被加载代码 `convert("L")` 截断**(≈88% 像素饱和,特征几乎恒定);(1x1)/c(6x2) 理想图是没裁剪的整幅图(能看到直接束斑),离所有轨迹帧很远(中位余弦距离 0.69/0.31),遮掉影子边缘以上区域后降到 0.17–0.33。用"遮束斑 + 修正 16 位"的锚点,远离锚点那一层 AUC 提高约 +0.03,靠近锚点那一层变差——于是有了 C1/C2。

## 三、需要如实说的限制
- 同一批 168 个标注组、三条生长轨迹;**没有任何实验检验"推广到新生长轨迹"**——这个核心缺口仍然开着。
- 模拟器只是运动学的,杆强度是随机替身,HTR 任意;仓库自带的模拟器压缩包没用上,更好的模拟器可能结论不同。
- C1 的"靠近锚点"层与基线完全相同(门控的构造),它的收益全在远离锚点层;门控阈值 0.03 等于远离锚点的定义(冻结前定好,没有调)。
- 开发在 20 个种子上试了约 45 个变体(赢家诅咒);容器中途重启两次,后台任务都是可恢复的。
