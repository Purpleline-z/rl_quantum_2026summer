# Development plan TD0 — transductive and forward-in-time evaluation (branch claude/transductive-20261014; written before the first development screen finished)

## Protocol extension (stated here, repeated in PREREGISTRATION_TD1.md)
1. **Transductive** (graph node sets; features only, never labels). `std` = the repository's rule (held-out images excluded from the graph, "inductive attachment"); `trans` = std plus the images of the held-out (validation / test) groups as unlabelled nodes. The head, the loss and the schedule are those of `lap3_k10_st4`; only the node set of the Laplacian regulariser / score propagation / posterior changes. Outer-test ideal images are never nodes (as before).
2. **Forward-in-time.** Calendar axis: runs are ordered by date (RR220204A < RR220206A < RR220411A), an image's time is (run rank, frame number), a pair group's time is that of its *later* image (the group exists once both images exist). All 168 groups can be assigned a time (every image of every group is a trajectory frame; 0 groups cannot); 104 are cross-run pairs, 29 / 35 / 104 groups have their time in the three runs. A cut is "the first n groups in calendar order are the past" with n ∈ {12, 24, 40, 54, 70, 90} (two per run: 204A = groups 1–29, 206A = 30–64, 411A = 65–168), n jittered by ±2 with the seed. Labelled = all past judgments whose images are not in a test group (the repository's identity rule; ≈ 8–78 groups, 25–237 judgments). Test windows: **FA** = next 40 groups after the cut, **FB** = the following 34 groups (the test sizes of Splits A and B; they play the role of "the two splits" of the forward endpoint). Only decisive judgments are scored, ≈ 56–80 per FA window, 46–68 per FB window per cut.
3. Graph node sets in the forward protocol: `ind` = past frames (time ≤ cut) + ideal images (deployment-inductive: the future does not exist yet; images of test groups excluded); `std` = repository graph (future non-test frames are nodes); `trans_test` = ind + the test images; `trans_win` = all frames that exist when the window is scored (time ≤ time of the window's last group; causal transduction); `trans_fut` = all frames of the data except outer-test ideal images.
4. Baseline `BASE` = `lap3_k10_st4` on `ind` (standard split: `std`). Tuned graph-free control `G0` = `aw8_all_st2lr0.5`. Every graph claim has the shuffled-graph control (node identities of the adjacency permuted).

## Variants to screen (development seeds 10500–10519; ≤ 20 seeds; everything tried is logged in PROGRESS_LOG_transductive.md)
L: Laplacian with test frames as nodes (`trans_test`, `trans_win`, `trans_fut`, λ); SP: test-time score propagation over the graph (no retraining; on the inductive graph test images attach to their nearest nodes, on transductive graphs they are nodes); TW: recency-weighted loss; AQ: anchor posterior (label spreading of the ideal-image classes) propagated over the node set, used as a ranking loss on random node pairs; CT: co-training on pseudo-labelled pairs of unlabelled frames (2 rounds). Decomposition: `ind → std → trans` (how much of the advantage is the future frames, how much the test frames themselves).

## Endpoints
Primary (forward): FA and FB, AUC / accuracy (log-loss secondary), per-seed mean over the 6 cuts, paired against BASE (identical labelled set and head seed). Secondary: standard random splits A/B at budgets 10/20/40/60 (transductive vs inductive: how much of the advantage is the test frames being in the graph), anchor-far stratum (> 0.03 cosine distance from every typed anchor), time-blocked split. Intervals: bootstrap over seeds and over test groups.
