**Ablation: is the decisiveness weight needed?** The same coverage rule with the decisiveness factor set to 1 (`typed_coverage_uniform`; pre-registered as descriptive, seeds 1600–1639, same Random cells) has gains of +0.006, −0.001, +0.004 and +0.007 in log-loss (AUC +0.003, +0.001, −0.006, −0.006; none significant), against +0.023, +0.009, +0.029 and +0.023 for the rule with the weight. The differences are +0.017, +0.010, +0.025 and +0.016 in log-loss (raw p 0.16, 0.47, 0.048, 0.17), +0.005, +0.003, +0.010 and +0.008 in AUC (raw p 0.17, 0.40, 0.034, 0.16) and +0.008, +0.006, +0.014 and +0.012 in accuracy (raw p 0.045, 0.21, 0.018, 0.087). Plain coverage in the graph-propagated pair space therefore gives little by itself; the gain comes with the weight that is computed from the type posterior (and, in split B, partly from the type alone, as the type-only control shows). Given §5.15's observation that decisive judgments are not more useful for this endpoint, the weight probably acts as a type-dependent allocation of the budget, not through predicted decisiveness; this was not tested.
