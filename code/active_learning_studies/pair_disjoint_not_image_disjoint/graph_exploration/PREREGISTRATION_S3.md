# PREREGISTRATION_S3 — larger replication of the two typed-coverage rules (written 2026-10-12 ~12:30 UTC, after S1, S2, the oracle diagnostic and the sequential dev screen; BEFORE any seed 8400–8479 was run)
Reason: S1/S2 effects of `tdc` and `qcov_alloc` are small (+0.005 to +0.011) and the per-block tests (30–35 seeds, 16 or 8 tests) have limited power; the oracle diagnostic says the ceiling is low, so the question left is whether the small gains and their graph-specific part are real on this dataset's split variability. S3 uses 40 fresh seeds per start mode. Same hypotheses chosen after seeing S1, so not independent of that choice.
Rules and code unchanged: `tdc`, `qcov_alloc`; comparator arms `tdc_typeonly`, `tdc_shuffled`, `qcov_alloc_shuffled`; Random = 5 draws; learner aw8_all.
Blocks (each once): regular start seeds 8400–8439; cold start (10 random initial judgments) seeds 8440–8479.
Family per block: {tdc, qcov_alloc} x {A, B} x {acc, auc} = 8 tests (two-sided Wilcoxon over seeds; Holm within block). 'Beats Random' = all four cells of a rule Holm < 0.05. Graph-specificity (paired difference to controls, uncorrected, AUC): `tdc` − `tdc_typeonly`, `tdc` − `tdc_shuffled`, `qcov_alloc` − `qcov_alloc_shuffled`, reported per split; a graph claim needs a positive difference with p < 0.05 in both splits for the shuffled control (type-only is a weaker control and is reported but does not by itself support a graph claim beyond 'the type posterior beats type identity').
Pooled descriptive estimates over S1 + S2 + S3 (regular: 35 + 30 + 40 = 105 seeds; cold: 105 seeds) with seed-bootstrap intervals.
