## 2. What was built
- **Free scores** (`new_directions/nd_propagate.py`): one free score per type for every graph node (the 1120 kNN-graph nodes plus extra nodes for typed anchors that are not graph nodes — the 28 outer-test ideal images — and for labelled images that are not nodes; held-out pair-group images are never nodes). Objective per type column (convex): Bradley–Terry likelihood of the labelled judgments (the repository's winner / tie / not_apply terms, hinges smoothed), the anchor ranking terms (weight 8, all ideal images), the bad-image term, λ × Laplacian penalty over all nodes, ρ × ridge. Solved exactly by damped Newton with the dense Hessian (matches 3000-iteration L-BFGS to 7 digits, ≈ 1.5 s per fit). **No parametric head.** Test images (never nodes) get the softmax(sim/0.05)-weighted mean of the scores of their 5 nearest nodes.
- **Baselines / controls:** `ls` label spreading of the anchors' class one-hots (no judgment used); `kn` free scores without Laplacian read out at the nearest *scored* nodes (nearest neighbour in score space); `fs_lam0` free scores without penalty (memorisation); shuffled-graph versions `*_sh1` (adjacency node identities permuted, extras attached to random nodes); `aw8_all_st2lr0.5`.
- **Hybrids:** (a) `hy_*` head `lap3_k10_st4` + free residual (penalties on the residual); (b) `ds_*` the Laplacian head with pair-difference distillation of a free-score teacher on unlabelled nodes/edges; (c) `st_*` in-budget cross-validated stacking weight (all types), and `rt_*` / `bl_*` per-type fusion (HTR judgments use c × d_free / d_head + w d_free, other types keep the head).
- **Evaluation:** standard endpoint (splits A/B, budgets 10/20/40/60, identical random label sets, held-out decisive preference judgments), anchor-far stratum (both test images > 0.03 from every typed anchor, `rt_a1b.py` definition), time-blocked contexts (`rt_blocked.py`) and cold start (`ND_INITIAL=random`).
- Development plan `PREREGISTRATION_SP0_development_plan.md` (+ amendment SP0b) was written before any development result was read; amendment SP0b after the screens and the HTR-route observation, before any confirmation seed.
