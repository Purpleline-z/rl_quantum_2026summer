# 一页中文摘要:红队审计(分支 `claude/redteam-20261013`)

任务是"尽力证伪最近确认的结论,并独立复现"。完整表格(脚本生成)在 `RESULTS_redteam.md`;预注册在 `PREREGISTRATION_RT1.md` 和 `PREREGISTRATION_RT2_anchor_strict.md`(确认种子 8850–8884,冻结后才运行)。所有结果仍是同一批 168 个标注组、3 条生长轨迹(284 帧)。

## 先说结论
**没有发现实现错误,也没有"路径级"的数据泄露;拉普拉斯学习器的增益在多数更严格的评估下仍然成立,但它主要集中在"与带类型的锚点图像几乎相同"的留出判断上;而更早的"锚点权重 8"的收益,在去掉近似复制的锚点后不成立。**

## 预先登记并在新种子上确认的(35 个种子,Holm 校正)
1. **标准终点复现**:`lap3_k10_st4` 相对调好的不用图学习器,AUC +0.019/+0.018(A/B),准确率约 +0.02,全部显著 → 稳健。
2. **去图重复**(把图里与留出图像距离 ≤0.003 的节点删掉):AUC +0.021/+0.018 → 稳健。
3. **时间分块划分**(整段 100 帧留出,训练/候选池/图里去掉前后 25 帧):AUC +0.023,准确率 +0.019 → 稳健。
4. **去掉近似复制锚点**(把与留出图像几乎相同的理想图从所有学习器的锚点里去掉):AUC +0.025/+0.030,准确率 +0.025/+0.035 → 稳健(增益比标准终点还大)。
5. **只看远离所有带类型锚点的留出判断**(两张图都 >0.01 远):AUC 增益 +0.003/+0.001(区间含 0),准确率 +0.018/+0.010(Holm 后不显著)→ **变弱**:AUC 增益主要来自靠近锚点帧的判断,长训练在远离锚点的判断上没有额外帮助(开发种子)。
6. **锚点权重 8 的检查**:所有锚点都在时,在远离锚点的判断上增益稳健(AUC +0.025/+0.026),说明它不是锚点复制的假象;但**把近似复制的锚点去掉后**,收益消失(AUC −0.008/+0.003,准确率 −0.013/−0.007)→ 不成立。也就是说,这项收益依赖带类型锚点离留出帧很近。
7. **独立复现**:自己重写的干净实现(自己的损失、自己的内容 hash 身份过滤、自己的 kNN 图)在相同标注集上与主实现的得分差 ≤2e-15(拉普拉斯项的边采样随机种子沿用了主实现的约定)。

## 开发观察(不是证据)
- 数据几何:测试图像几乎都有近乎重复的训练帧;约 39% 的留出判断含有一张与某个带类型理想图相距 ≤0.001 的图像(≤0.01 约 59%)。严格去重标注数据不可能(去掉后候选池只剩 13–22%)。
- 按"对训练图像的新颖度"分层,增益在所有四个分位都为正,不是只在最不新颖的那一层。
- 有一张留出图像在标注/候选池里有内容完全相同的"孪生"(3/10 个审计格子),量级很小。
- `lap3_k10_st4` 在 RT13 判断和远离锚点的判断上对数损失比调好的不用图学习器差(过度自信)。
- 已存确认结果对聚合方式/检验方式基本稳健,只有图学习器确认 2 里 `lap3_k10` 相对 `aw8_all` 的准确率增益在若干聚合下很弱。
- 单次拟合噪声大:头部初始化的标准差(AUC ≈0.012)与格子间标准差同量级,所以需要对很多标注集取平均。

## 局限
只有同一批 168 组和 3 条轨迹,无法评估新轨迹/新样品;阈值(0.01、0.003、100/25 帧)来自开发种子;距离用的是冻结 SimCLR 特征空间(和图同一几何)。
