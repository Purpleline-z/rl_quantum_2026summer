# Literature notes — graph-kernel Gaussian process for the reward head (branch claude/graph-gp-20261014)

Statements come from WebSearch result summaries (摘要); no paper text was opened (arXiv/CVF blocked).
1. **Sindhwani, Niyogi, Belkin, "Beyond the Point Cloud: From Transductive to Semi-Supervised Learning", ICML 2005** (摘要): data-dependent norms on an RKHS warp the structure of the space to the geometry of the unlabelled data and yield explicit formulas for the new (deformed) kernels, which are defined for unseen points — the construction used here, k~(x,y) = k(x,y) − k_x^T (I + βLK)^-1 βL k_y (my reading of the construction; the search did not return the formula). A later paper (as summarised) notes that performance varies strongly with the warping and that it is unclear how to optimise it — which is why the strength β is learned by evidence / cross-validation here.
2. **Kapoor, Ahn, Qi, Picard, NIPS 2005**, hyperparameter and kernel learning for graph-based semi-supervised classification (摘要): Bayesian framework, hyperparameters (graph similarity, Laplacian transformation, noise) by evidence maximisation with approximate inference (EP), posterior mean written through the kernel matrix. Direct precedent for evidence-tuned graph hyperparameters.
3. **Borovitskiy et al., "Matérn Gaussian processes on graphs", AISTATS 2021** (摘要): graph Matérn kernels from the Laplacian's spectral decomposition, sparse precisions for integer smoothness; the diffusion / (I + βL)^-1-type kernels of the task are members of this family. Marginal-likelihood training is standard for them.
4. **Chu & Ghahramani, "Preference learning with Gaussian processes", ICML 2005 / JMLR 2005** (摘要): GP prior on a latent utility, likelihood a sigmoid of f(x_i) − f(x_j); Laplace approximation around the MAP gives a Gaussian posterior (Σ^-1 + Λ)^-1, the Laplace evidence and its analytic hyperparameter gradients; later work points out limitations of the GP predictive variance for preference learning. The model of this study, with one latent function per type and typed anchors as additional constraints.
