# Literature notes — recipe search (branch `claude/recipe-20261013`)

Only what the search results said is recorded; "(abstract/snippet)" = read from a search snippet, not from the full paper. None of these results was run on this data; they only motivated which knobs were screened.

- **Tie models.** Rao & Kupper (1967, JASA 62) add a threshold parameter to Bradley–Terry so that ties become possible; Davidson (1970, JASA 65) is the other standard tie extension (abstract/snippet). "On Extending Direct Preference Optimization to Accommodate Ties" (arXiv 2409.17431) replaces the Bradley–Terry term by Rao–Kupper / Davidson variants; its authors report similar task performance at much smaller KL from the reference model (snippet). A 2024 chatbot-ranking paper (arXiv 2412.18407) finds the original Rao–Kupper model predicts the win matrix reasonably but ties less accurately (snippet). → screened here as `rc_rk` (Rao–Kupper likelihood with a learned margin); `rc_softtie` (soft 0.5 target) is implemented but was not screened (budget of 12 variants).
- **Pairwise loss form.** RankSVM (hinge), RankNet (logistic), RankBoost (exponential) differ in the penalty only; the generalisation bounds quoted in the snippets do not separate hinge from logistic, and no source compared them on small training sets (snippets, mostly secondary sources). → `rc_hinge` is an empirical question here.
- **Mixup / dropout on small data.** "On Mixup Regularization" (JMLR 23) argues that dropout acts through input perturbations only while mixup correlates input and output perturbations (snippet); "Dropout Reduces Underfitting" (arXiv 2303.01500) reports that when data are large or the model small the best drop rate is 0 (snippet). No source tested mixup on pairwise preference learning or on frozen features (the search said so explicitly). → `rc_mix` (pair-level mixup, soft targets) and `rc_do0.3` are untested-in-literature knobs here.
- **Laplacian regularisation.** Pure graph-Laplacian penalties can produce spikes at labelled points in the very-few-labels limit; p-Laplacian regularisation avoids them (SIAM J. Math. Anal., arXiv 1707.06213; snippet). The search found nothing on how schedule, weight decay or dropout interact with the Laplacian term in deep heads. → the interaction is an empirical question; the neighbouring study `graph-mechanism` already found that an L1 / Huber penalty does not help.
- **Not found / not used:** a head-to-head of logistic vs hinge on tiny pairwise sets; mixup for Bradley–Terry reward heads; cosine decay for the head of a frozen-feature reward model.
