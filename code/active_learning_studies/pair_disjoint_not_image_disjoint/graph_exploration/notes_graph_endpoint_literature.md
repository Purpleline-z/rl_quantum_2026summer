# Literature notes for the graph-endpoint study (2026-10-13)
Only what search results stated; "(summary)" = search summary, paper text not opened. Earlier notes (`notes_overnight2_literature.md`, `notes_graph_learner_literature.md`, `notes_graph_selection_literature.md`) are not repeated.

## Inductive vs transductive evaluation
- **Chapelle, Schölkopf, Zien, Semi-Supervised Learning (MIT Press 2006; summary).** Laplacian/graph methods are intrinsically transductive: they return the decision function only on the points of the graph, not a function on the whole input space; making them inductive is the out-of-sample-extension problem, usually handled by re-deriving a new point's value from its neighbours. Relevance: our *inductive* classification protocol (test ideal images attach to their k nearest graph nodes) is exactly that extension; the *transductive* protocol (test images as unlabelled nodes) is the classical graph setting and is the looser one.
- **Planetoid (Yang et al. 2016) and GraphSAGE (Hamilton et al. 2017; summaries).** Report inductive and transductive variants separately; the original GCN is transductive because it needs the full graph. Relevance: supports reporting the two protocols in separate tables and never mixing them.

## How much unlabelled data helps
- **Singh, Nowak, Zhu, "Unlabeled data: now it helps, now it doesn't" (NeurIPS 2008; summary).** Minimax finite-sample analysis under a cluster assumption: semi-supervised learning beats supervised learning when the components are discernible from m unlabelled points but not from n < m labelled points; m must grow polynomially (exponentially) with n for polynomial (exponential) decay; the benefit may be a better constant, not a better rate. Relevance: predicts a dose-response in the number of unlabelled images only while the cluster structure is not yet resolved; it can also saturate or be absent, so a flat dose-response is a legitimate outcome.
- **Calder, Cook, Thorpe, Slepčev, Poisson learning (ICML 2020; summary).** Plain Laplacian learning degenerates to nearly constant predictions at very low label rates; Poisson learning (sources/sinks) is more stable. Relevance: our classification labels are 88 references (about 22 per class) — not very low — but the lap head sees very few judgments at small budgets; the "constant solution" failure mode is a possible reason for a graph method to lose to NN.

## Evaluation under group shift
- **Leave-one-group-out and blocked cross-validation (guidance pages; summary).** When observations are autocorrelated a held-out point usually has a near-duplicate in training, so random splits understate error; remedies are holding out whole groups (leave-one-region-out) and an embargo gap around the test block; groups should come from authoritative metadata, not from clustering the features; separation is necessary but not sufficient (too-fine groups leak, too-coarse ones leave too little training data); scores are expected to be lower and more variable. Relevance: our "harsh" preference splits hold out whole growth runs (the file-name run id), which is group-level hold-out with authoritative metadata; the existing protocol is already image-disjoint but not run- or time-disjoint, so neighbouring frames of the same run can sit on both sides.
