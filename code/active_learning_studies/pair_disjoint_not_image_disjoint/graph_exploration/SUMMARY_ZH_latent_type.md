# 一页摘要:潜在类型(Dawid–Skene)模型 —— 结果:没有改进

**问题**:把每张图像的"类型归属"当作潜变量,用 EM 拟合判断结果(决定性/平局/not_apply)的混淆表(锚点固定部分图像的类型,kNN 图做先验),再把后验用在 `lap3_k10_st4` 里(软伪锚点、可回答性加权、辅助目标),能不能提高留出配对组的偏好预测?特别是离所有锚点都远(>0.01)的判断。

**结论(预先登记,两个独立确认块 10730–10764 与 10765–10799,各 35 个新种子)**:
- 4 个冻结候选**没有一个**满足成功规则。标准终点 16 个检验里 Holm p<0.05 的数量:确认 1 为 0 个;确认 2 只有伪锚点候选(C4)显著**变差**(A 划分 AUC −0.005,Holm p=0.018)。锚点远处(far)也没有 Holm 显著的增益。
- 辅助目标候选(C1)在确认 1 里 8 个增益全为正,但数值只有 +0.0003…+0.010 AUC;确认 2 里 A 划分变成 −0.002,没有复现。唯一两个确认块都为正且名义显著的格子是 B 划分、far 层(AUC +0.010 / +0.008,未校正 p=0.008 / 0.005,Holm 0.113 / 0.083)。
- 时间分块划分(确认 1):没有候选更好,可回答性加权和伪锚点显著更差(确认 2 的分块划分没来得及跑)。
- 对照:**随机类型归属**明显更差(−0.010…−0.015 AUC),**打乱先验**更差(−0.004…−0.006),说明后验里确实有信息;但**只用图先验、没有结果似然**的对照几乎一样好:C1 比它高 +0.0014/+0.0024(确认 1)和 +0.0015/+0.0006(确认 2),只有一个格子名义显著。所以"用判断结果推断类型"相对"图先验自训练"的额外价值很小。

**为什么(机制,多为开发观察)**:(1)图先验已经包含了可回答性:用全部理想图做先验时,两张图对该类型的先验质量都很低则 61% 是 not_apply,有一张≥0.9 时只有 3%;(2)结果似然只能更新出现在已标注判断里的 ≈38–104 张图,而图有 ≈1100 个节点;藏掉 25% 锚点后,图先验恢复其类型 76.3%,加上判断结果只到 76.6–77.0%;(3)head 已经通过 Laplacian 项和锚点损失拿到同样的信息,再当伪锚点或推断时偏移(开发里 λ≥0.5 全部变差)只是把先验的错误再加一遍;(4)EM 学到的混淆表合理(两张都属该类型→平局 59–68%,not_apply 4–6%;只有一张→该类型的图赢 73–81%;都不属于→not_apply ≈60%),但数据太少,不能为每个类型单独拟合。

**诚实的限制**:同一批 168 个配对组换种子重新划分(p 值偏乐观);确认每个种子只用 1 组随机标注集;预先登记写在会话约 2 小时 40 分处(比计划的 4.5 小时早,因为开发筛选全是平的),文件里写的 05:30 与容器时钟(05:23)略有出入;"远离锚点"的差距**没有被缩小**。
