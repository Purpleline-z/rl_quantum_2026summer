# GPU / lab tasks left for you (graph-endpoint study)
Everything here ran on CPU with frozen SimCLR features and the 168 labelled pair groups.

1. **Harsh splits need more test data, not more seeds.** The held-out-run and held-out-temperature tests have 28 and 12 test groups (50 and 26 decisive judgments) and 3 growth runs; seed-level significance cannot fix that (bootstrap intervals over test groups include 0). The decisive experiment is new labelled comparisons from growth runs that are NOT among RR220204A / RR220206A / RR220411A, scored with models trained on the existing 168 groups (with and without the Laplacian term; `lap3_k10` vs `aw8_all`). Even 30–40 new labelled groups from a new run would roughly double the independent test evidence.
2. **Graph quality (encoder) is the untested lever.** The classification result says the SimCLR kNN graph links different classes about 20% of the time; better features (end-to-end fine-tuned encoder, DINOv2/CLIP if the hosts can be allowed; the baseline branch could not download them) should change the graph, and the dose-response result says the number of nodes is not the limit. GPU: rebuild the graph from a fine-tuned encoder and rerun `ge_run_harsh.py` / the preference runs.
3. **End-to-end fine-tuning with the Laplacian term** (the term is a penalty on the head scores of graph nodes; in a fine-tuned model it needs the nodes' features recomputed each step) — GPU only.
4. **Prospective growth data.** The dose-response says benefit saturates at a few hundred nodes of the right kind, so a new run does not need to be large to be useful as unlabelled data; but it does need pair labels from that run to measure anything. Plan: label a few dozen pairs from the next run, keep them as a fixed test set, compare `aw8_all` and `lap3_k10` trained on all existing groups.
5. **Classification endpoint.** Nothing in this study suggests a graph classifier will beat logistic regression on the 28-image test; the endpoint saturates at about 0.88–0.90 and its noise (about ±0.06 per seed) is as large as any plausible difference. If a classification claim matters, it needs a larger external test set of ideal images, not a new method.
