# RHEED Trajectory Ordering Analysis

## Question

This descriptive study checks what chronological ordering can be recovered from trajectory filenames and records gaps or ambiguity without assigning reconstruction labels.

## Data, split, and model version

It uses trajectory image paths and filename-derived ordering fields only. There is no train/validation/test split, no preference label, and no trained model in this study.

## Use in the technical report

Its outputs support only cautious descriptive statements about observed frame ordering. They are not used as accuracy evidence or as a constraint in the current active-learning conclusions.

## Comparability limits

Filename order is an observation, not a physical-state annotation. This study cannot establish a growth-transition sequence and is not comparable to either active-learning protocol.
