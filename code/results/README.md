# Results

`published/` is the compact, Git-tracked evidence set cited by the root technical report. `local_runs/` preserves historical job states, checkpoints, utility caches, and intermediate outputs. It is ignored by Git and is never deleted by this reorganization.

- `representation_exploration`: descriptive PCA/t-SNE and representation metrics.
- `fixed_protocol_3seed`: initial controlled comparison.
- `endpoint_extension_5seed`: budget-100 endpoint over five seeds.
- `endpoint_extension_15seed`: budget-100 endpoint over fifteen seeds.
- `budget_curve_5seed`: budgets 10–100 over five seeds.
- `diversity_and_coverage`: diagnostics, not primary evidence.
- `legacy_context`: protocol note for excluded sequential exploration.
